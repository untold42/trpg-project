| 项 | 内容 |
|---|---|

## 三、当前架构要点

- **状态现拼**：`游戏数据/*.json` 每次 LLM 调用现拼，放 messages 末尾，只一份、永远最新。
- **过程日志**：`sessions/current.jsonl` 每轮追加；`history` 只存纯叙事。
- **统一事件流**：后端→前端只有一条契约 —— `chat`/`narration` + `type:"ui"` 旁路。
- **信息边界**：`gm_memory`=客观真相；`char_memory[owner]`=某角色主观认知（🚧 引擎侧未做）。
- **硬事实由代码裁决**：时间 / 距离 / 方位 / 城内城外 / 骰值由代码算并注入，模型只渲染。

> 现状**时间**存于 `游戏数据/基本信息.json` 的「时间」字段（`日期` / `时辰` / `刻`），
> 由工具 `update_time` 离散推进；`engine.current_game_time()` 渲染成 `1220-01-16 辰时一刻`。

## 四、改革 v0.2 总览（地图为主 UI + 连续时钟）

### 动机

现状是"**聊天框为主 UI**"：玩家打字 → LLM 叙事 → 地图只是菜单里一页。
改革后是"**世界为主 UI**"：

```
地图（主界面，WASD 自由走）
   └─ 按 Enter → LLM 场景（背景图 + 叙事）→ 离开 → 回地图
```

### 五个决定（已拍板）

1. **地图升为主 UI**，玩家是一个可 WASD 操控的角色（先键盘，后手柄 + 语音）。
2. **后端连续时钟**：探索与叙事都实时流动；菜单 / 历史 / 战斗 / LLM 请求窗口冻结。
3. **单一标量时钟**：只维护"最新值"，日期/时辰/刻/昼夜全部派生。
4. **时间随状态现拼每轮发给 LLM**（**刻级粒度**）。
5. **左上角古代会动的钟**（HUD）。

### 实施进度

## 五、三模式状态机

```
        ┌────────────────────────────────────────────┐
        │              探索模式（地图）                │
        │  WASD 自由走 · 时钟 RUNNING · 无 LLM          │
        └───────┬──────────────────────────┬─────────┘
                │ Enter（与当前位置/POI 交互）│ Enter（敌对）
                ▼                          ▼
        ┌───────────────────┐      ┌───────────────────┐
        │   叙事模式（场景）  │      │   战斗模式         │
        │  背景图 · LLM · 钟 RUNNING（请求窗口暂停）│  回合制 · 钟 ACCRUING │
        └─────────┬─────────┘      └─────────┬─────────┘
                  │ 「离开」按钮 / 叙事结束      │ 战斗结束（结算时间）
                  └──────────────┬────────────┘
                                 ▼
                            回到探索模式
```

| 模式 | 时钟 | 主交互 | LLM |
|---|---|---|---|
| 探索 | `RUNNING` | WASD / Enter | ✗ |
| 叙事 | `RUNNING`（请求窗口 `PAUSED`） | 行动 / 说话 / 继续 | ✓ |
| 战斗 | `ACCRUING`（回合折算） | 战棋 | 仅思路判定 |
| 菜单 / 历史 / 失焦 | `PAUSED` | 面板 | ✗ |

### 实现（2026-09-15）

- **前端**：`GameController` 用 `gameMode: "explore"|"narrative"|"battle"` 驱动：
  - 探索 = 整屏 `<GameMap zoom={18}>`（WASD 连续移动 + 相机死区跟随；`playerOverride` 覆盖玩家位置；
    `extraFootprints` 即时揭示迷雾；按钮 / 古钟保留）；
  - 叙事 = `GameScene`（背景 + 立绘 + 对话框）——探索时用 `display:none` 隐藏而**不卸载**
    （叙事进度不归零）；
  - 战斗 = `BattleScene`。
- **切换**：探索 → 叙事由**玩家输入**触发（`sendAction` 顺带带上 `坐标`/`上一坐标`）；
  叙事 → 探索**只由主持人裁定**（工具 `resume_exploration` → UI 事件 `kind:"mode"`）；
  战斗由 `start_battle`（`kind:"battle"`）开启，结束回叙事。
- **后端**：`/action` 收到 `坐标` → `_apply_move()` 调 `update_location`（更新位置 / 足迹 /
  城内城外），并向本轮注入系统提醒 **【移动】梁峰自「A」来到「B」，相距约 N 米。（耗时提示）**
  —— 硬事实由代码给，模型只叙事（总纲第 5 条）。

> **WASD 连续移动**（2026-09-15）：`Map.tsx` 的 `ExploreControls` 用命令式 `L.marker` + rAF
> 逐帧更新位置与相机跟随（**不触发 React 重渲染**）；真实速度 = 游戏内步速 `1.4 m/s` × 时钟倍率
> （时间快 15 倍 → 标记也快 15 倍），保证游戏内步行速度真实；输入框聚焦时不拦截 WASD。
> **不能用点击瞬移**（点地图只看 POI 信息，不移动玩家）。**碰撞已完成**：水域 / 城墙阻挡，城门 25m、桥 100m、路∩水 为通道（见 §7.2）。
>
> **上一轮状态 + 当前状态**：`engine` 维护一个**长度 2 的栈**（`state_stack = deque(maxlen=2)`）
> ——每轮末 `append(本轮状态)`，旧状态自动挤掉；下一轮把**栈顶**（上一轮）与
> `===== 当前状态 =====` **一起**发给 LLM。探索时时间在流动、玩家在走动，
> 模型自行对比时间 / 地点 / 数值的变化，**代码不计算差值**（只两份、不累积）。

## 六、连续时钟（核心）

### 6.1 数据模型：一个标量

```
单一真相源 = 一个单调递增的整数标量「游戏秒」（自纪元起）
其余全部派生：日期 / 时辰 / 刻 / 昼夜 / 季节 / 天气
```

**为什么不用维护日历对象**：**"过去"不需要时钟** —— `current.jsonl` 每行已带当时时刻。
标量只管"现在"，历史记录里存"那时"。**不需要会随时间演化的日历结构。**

落点（二选一，推荐前者）：
```
trpg-server/游戏数据/时钟.json     ← 新建，独立文件
  { "游戏秒": 1234567, "状态": "running" }
或并入 基本信息.json 的「时间」字段（需迁移现有 日期/时辰/刻）
```

投影到 `基本信息.时间`：`{日期, 时辰, 刻, 纪年, 干支}`——`纪年`/`干支` 是**给 LLM 看的**
（年号由后端裁决，不让模型猜）；`时钟.json` 本身**不进 LLM 上下文**（裸秒数徒增困惑）。

### 6.2 状态机

```
RUNNING    探索 / 叙事（非 LLM 请求期）—— 实时流动
PAUSED     菜单 / 历史记录 / 窗口失焦 / LLM 请求窗口内
ACCRUING   战斗 —— 冻结实时流，按回合累积，结束时结算
```

**速率**：推荐 **1 真实分钟 = 1 刻（15 游戏分钟）**，即 1 游戏日 = 96 真实分钟。
做成 config，方便调参。

| 参考 | 数值 |
|---|---|
| 1 游戏日 | 96 真实分钟（1.6 小时） |
| 白天→黄昏 | ~48 真实分钟 |
| 走完全城（约 2 刻路程） | ~2 真实分钟 |

### 6.3 两个显示粒度（关键）

| 用途 | 粒度 |
|---|---|
| 存储（真相源） | **秒**（整数，避免浮点漂移） |
| **发给 LLM** | **刻**（粗，防微抖动干扰模型） |
| 前端古钟动画 | **秒**（细，钟要"会动"） |

> ⚠️ **发给 LLM 只用刻级**。否则每轮时间差几秒，模型会困惑"时间怎么一直在跳"。
> **UI 细、LLM 粗**。

### 6.4 前端插值（别每帧轮询后端）

```json
// 后端给一次锚点
{ "游戏秒": 1234567, "服务端墙钟": 1726900000.0, "状态": "running" }

// 前端本地插值（requestAnimationFrame）
当前游戏秒 = 游戏秒 + (Date.now()/1000 - 服务端墙钟) × 倍率   // 仅 RUNNING
```

- 每次 `/action` 响应**顺带带一份新锚点**重新校准（防漂移）。
- `PAUSED` 停插值，`RUNNING` 重设锚点。
- 古钟组件**只更新一个 CSS 变量**，不要每帧 `setState`。

### 6.5 与现有系统的联动

| 系统 | 改动 |
|---|---|
| `update_time` | **降级**为"叙事跳时"通道（睡一夜 / 赶路三天）；环境时间由时钟自动推进 |
| 时间权威护栏 `engine._check_time_authority` | **换语义**：叙述有大幅跳时却没调 `update_time` → 提醒 |
| `weather_system` | ✅ 时钟**跨游戏日**时自动切当天天气（`time_flow.pump()`） |
| `world_worker` | ✅ 时钟**跨日**时入队（`time_flow.pump()` 调 `on_turn_end`；`MAX_TICKS=10` 兜底挂机跨多日） |
| `精力`（`状态.json`） | ✅ 跨**时辰**随昼夜流逝（夜时辰熬夜更狠）；工具 `sleep` 推进并恢复 |
| `save_pipeline` | 快照 + 分段誊写使用连续时钟；确认字符串格式一致 |
| `GameSession` 快照 / `abandon` | 快照必须含时钟标量 |

**时间双通道模型**：

```
环境时间（走路 / 说话 / 观察）  ←  时钟自己流
叙事跳时（睡一夜 / 赶路三天）    ←  LLM 调 update_time
```

## 七、地图为主 UI + WASD 探索

### 7.1 渲染：保留 Leaflet，加一层 Canvas

Leaflet 是**地图库**不是游戏渲染器。WASD + 碰撞 + 动画下它会吃力，但**不要推倒它**
（瓦片、点击层、迷雾、`/explored` 都在上面）。方案：

```
Leaflet（瓦片底图 + 坐标系）        ← 保留
  └─ Canvas Overlay（rAF 游戏循环）  ← 新增：角色 / NPC / 特效 / 碰撞可视化
```

### 7.2 碰撞：预烘「可走网格」

WASD 自由移动必须阻止穿墙 / 穿屋 / 入河。现有 `map_spatial.db` 只有几何、**未成图**（TODO §8.4）。

- MVP：从空间库**预烘一张可走栅格**（约 2m×2m；建筑=不可走，河=不可走或涉水，街巷=可走），前端查表碰撞。
- 后续可升级为真正的路网图（Dijkstra/A*）。
- 语义可复用战斗系统的 `blocked()` / `reachable_cells()`。

### 7.3 相机与控制

- 相机跟随角色；WASD（后续手柄左摇杆）产生 `MoveVector(x,y)`。
- **走路只更新坐标 / 时钟 / 足迹，不写 `history`**（否则 `current.jsonl` 被脚步刷爆）。
- 输入抽象层（见 §11），为手柄 / 语音留口。

## 八、Enter 进入场景（代码注入地理硬事实）

按 Enter 时，**代码先自动跑地理查询**，再让 LLM 生成场景：

```
按下 Enter
  → 代码：query_nearby / city_context / description / place_notes / 当前时刻 / 天气
  → 拼成「此地是什么、旁边有什么、什么时辰、天气如何」
  → 注入 prompt → LLM 生成叙事
  → 前端切到对应背景图（由坐标 / 地点类型确定，不再靠小模型猜）
```

- 这是**总纲第 5 条「硬事实由代码裁决」**的直接应用。
- 背景图改为**由坐标 / `ancient_kind` 确定性映射**，比小模型猜更稳、更省一次调用。
- 场景必须有**显式出口**（「离开」按钮），不能只等 LLM 说"你可以走了"。

## 九、足迹的复用

`游戏数据/足迹.json` 现为 `{"points":[{lon,lat,地点}]}`，当前仅用于 `/explored` 迷雾。

| 层级 | 用途 |

## 十、左上角古钟 HUD

```
┌─────────────────────────┐
│   ◜ 十二时辰环 ◝         │   子丑寅卯辰巳午未申酉戌亥 环绕
│     指针平滑旋转          │
│   ☀ ────●──── ☾        │   日月弧：昼在日侧，夜到月侧
│  未时 · 二刻              │   时辰 + 刻
│  嘉定十七年 三月初五      │   日期（年号 + 月 + 日）
└─────────────────────────┘
```

**元素**：① 十二时辰环 + 平滑指针 ② 刻刻度（8 格） ③ 日月弧 + 昼夜配色 ④ 日期文字。
风格：楷/宋体 + 青铜或木质配色。位置/层级/尺寸均为 CSS 变量（`--clock-top` / `--clock-z` / `--clock-size` …）。
**日期与年号来自后端锚点**（`anchor.纪年` / `anchor.干支`），前端不再自备年号表。

> ⚠️ 教训：曾加过「漏刻水滴」装饰，但它固定在盘底 → 正好落在 **午时** 位置，
> 被误读成「午时有事件」的游戏标记。**环上的任何固定装饰都会对上某个时辰**，故移除。

**技术**：SVG + CSS transform。指针角度 = `(游戏刻 / 96) × 360°`，由 **CSS 变量** 驱动，
rAF 每帧只改一个变量。整点换时辰时加一点转场 / 音效。

**战斗期间**显示 `战 · 第 N 回合`（冻结或逐回合跳），结束后一次性跳。

## 十四、风险与坑

1. **AFK / 失焦 = 世界暴走**：必须加 `visibilitychange` + `blur` 自动暂停。
2. **死地图**：地图若除"按 Enter 触发 LLM"外无内容，就是花哨的场景选择器。→ Phase 2 兜底。
3. **`update_time` 语义漂移**：环境时间自动流后，模型可能不再调它；护栏须从"推进了没落库"
   改为"大幅跳时却没落库"。
4. **足迹爆炸**：WASD 高频坐标必须降采样。
5. **显示粒度混用**：LLM 只喂刻级，UI 才用秒级。
6. **时钟连续化波及存档**：`save_pipeline` 分段誊写的时刻格式须与连续时钟一致。
7. **挂机跨多日**：`world_sim` 靠 `MAX_TICKS=10` 兜底；失焦暂停是主要防线。
8. **只跑一个后端**：两个 `python main.py` 会抢 5000 端口，表现为"改了没生效"。
9. **素材版权**：若日后封装发行，BGM / 背景图 / 地图数据（OSDbL）须先确认授权。

## 十五、验收标准

### 时钟
- [ ] 探索模式下站着不动，古钟持续走；打菜单 / 看历史 / 切窗口 → 停；关掉 → 续走。
- [ ] LLM 请求进行中，钟不跳（请求耗时不计入游戏时间）。
- [ ] 战斗结束，时钟一次性 += 回合数 × 每回合秒；跨时辰 / 跨日正确。
- [ ] `/action` 每轮的 prompt 里时间**只到刻**；UI 古钟**平滑到秒**。
- [ ] 存档 → 读档，时钟标量一致。

### 地图 / 移动
- [ ] WASD 能走，撞墙 / 撞屋 / 入河被挡。
- [ ] 相机跟随角色；走路**不产生** `current.jsonl` 行。
- [ ] 足迹增长受降采样限制（不随步数线性爆炸）。

### 场景
- [ ] Enter 时 prompt 含**代码注入**的 `query_nearby` / `city_context` 结果（非模型编造）。
- [ ] 背景图由坐标 / 地点类型确定，同一地点可复现。
- [ ] 「离开」按钮能回地图。

### 联动
- [ ] 时钟跨游戏日 → 天气自动切换；`world_sim` 入队。
- [ ] 叙述"睡了一夜"却没调 `update_time` → 下一轮出现时间提醒。
