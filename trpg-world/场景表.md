# 场景表（场景说明 + 地点类型映射）

> 本文件一份两节，代码按节名解析（`trpg-server/tools/小模型/ui_sim.py`）：
> - 「场景说明」：`- 场景名：情境说明` → 让小模型理解每个场景（`scene_descriptions()`）
> - 「地点类型映射」：`- 地点类型：场景1, 场景2` → 限定候选、防乱选（`scene_kind_map()`）
>
> **场景名的真相源 = `trpg-client/src/assets/背景_重构/` 的目录名，而目录名就是地图 kind 名。**
> 所以每个 kind 首选它自己的同名场景；后面跟的是同类兜底，供「自己的图还没出」时顶上。
> 代码只把**确实放了图**（`白天.png` / `黑夜.png` / `黄昏.png`）的目录算进候选——
> 没出图的 kind 自动落到 `室内` / `室外` 兜底组，不会选到一个前端拿不到图的场景。
>
> 新增/改动：出图到 `背景_重构/<kind>/` → 在「场景说明」加一行 → 在「地点类型映射」挂上。

## 地点类型映射

> 玩家所在地点的地图类型（`features.ancient_kind`）→ 允许的背景场景集合，**按优先级排列**。
> 叙事小模型只在此集合内选（+「无」＝保持当前）。候选越少越不乱选。
>
> `室内` / `室外` 是兜底组：地点类型查不到、或该类型一张图都没有时，
> 由叙事判断「屋里 / 屋外」后在对应组里选。
