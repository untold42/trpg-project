# 场景清单

> 场景名 → **适用情境说明**（供 `tools/ui_sim.py` 让小模型据此选背景）。
> 场景名必须与 `trpg-client/src/assets/背景/<场景>/` 目录一致；只有实际存在的场景才会进入候选。
> 新增场景：把图放进 `trpg-client/src/assets/背景/<场景>/`，并在下面加一行说明。

- 乡村：村落田舍、炊烟鸡犬；江南农家、乡野小院。
- 书斋：读书人的书房，书架案几、笔墨纸砚；读书、写字、密谈。
- 前线战场：两军对垒、尸横遍野；厮杀、军阵、烽烟。
- 卧室：私宅卧室，床榻灯烛；就寝、私密、夜深人静。
- 坊：唐宋城内的里坊街巷，坊墙坊门；城内居住区、寻常巷陌。
- 城墙：城头雉堞、城门楼；守城、登高望远、城防。
- 城市大街：城内主干大街，店铺林立、人来人往；市井繁华。
- 多人宿舍：通铺大炕、多人同住；镖局/军营/寺观的集体住处。
- 大船：大型江船海船的甲板与舱室；远行、水战、押运。
- 大街：一般的街道（规模小于"城市大街"）；走动、赶路。
- 客房：客栈的普通客房，一床一桌；投宿落脚。
- 客栈一楼大厅：客栈楼下大堂，方桌条凳、掌柜柜台；打尖、会客、打听消息。
- 客栈二楼大厅：客栈楼上的雅座回廊，临窗座位；宴饮、密谈。
- 客栈住宿房间：客栈的住店房间；歇息过夜。
- 寨子：山贼豪强的山寨，木栅箭楼；落草、聚义、劫掠。
- 寺庙：佛寺殿宇、香火钟磬；礼佛、借宿、避祸。
- 小岛：江河湖海中的小岛；荒僻、隐居、奇遇。
- 小巷：狭窄巷弄，青石板、两侧院墙；跟踪、偶遇、市井角落。
- 小溪：山间溪流、卵石浅滩；浣洗、行路、歇脚。
- 小船：乌篷船、渔船；摆渡、水乡出行。
- 山路：山间小径、石阶；赶路、伏击、行旅。
- 山野：山野林地、荒草野径；露宿、行猎、隐居。
- 山顶：峰顶远眺、云海；登临、论剑、观景。
- 崆峒玄功洞：崆峒派的洞府石室；门派、闭关、武学秘地。
- 庭院：宅院天井，花木回廊；家宅日常、待客。
- 星空：夜空繁星；夜观天象、静思、抒怀。
- 杏花仙的公主房：闺阁香房，陈设精致；女子居所、私会。
- 杏花林：成片杏花林；春游、赏花、幽会。
- 柴房：堆放柴草的杂物间；藏身、受罚、贫苦。
- 森林：茂密树林；迷路、追踪、野宿。
- 江河：大江大河，江面开阔；渡江、水战、远眺。
- 湖边：湖边岸柳、水波；散心、泛舟、密会。
- 灶房：厨房灶台锅碗；做饭、下毒、偷听。
- 田野：农田阡陌、稻麦；农事、逃匿、乡野。
- 画舫：装饰华丽的游船；水上游乐、听曲、宴饮。
- 监狱：牢房铁栅、刑具；囚禁、越狱、拷问。
- 码头：江边码头、货船装卸；出行、接船、市井。
- 破庙：荒废庙宇，蛛网尘灰；借宿、避雨、秘会。
- 脚店：路边小食店小旅店（比客栈简陋）；歇脚、打尖、打听。
- 茶肆：茶馆，茶桌、说书；喝茶、闲谈、探听。
- 荒郊野岭：荒山野地、人迹罕至；遇险、亡命、奇遇。
- 药铺：药铺，药柜、草药味；求医、买药、解毒。
- 街区：城中成片的街坊区；市井、穿行、落脚。
- 豪华的房间：陈设奢靡的上房私室；富贵、密谈、声色。
- 豪宅大堂：世家富户的正厅大堂；宴客、议事的堂皇之所。
- 铁匠铺：打铁铺子，炉火风箱；铸兵、修械、匠人。
- 锦香宫：锦香宫的宫室水榭；女修门派、收容之所。
- 镇子：城外集镇，店铺沿街；补给、歇脚、消息集散。
- 雪山：雪山冰川、凛冽苦寒；极险、绝境、苦旅。
