# 旅途骰子事件

> 所有非城市旅途通用——陆路、水路、海路。
> 规则：低顺高不顺——骰值越小越好。不发明新钩子——异象/麻烦从已有钩子（泥教、千灯楼、各江湖势力等）中推进。
> 与日常骰子的区别：旅途只需一次骰子（调用 `travel_event_dice`），混乱值修正为加法，无二级骰。

## 流程

```
非城市旅途 → 调用 travel_event_dice 工具
  → 工具掷 d100 + 混乱值×0.25
  → 主持人按返回的等级与方向叙述
```

## 事件等级

| 最终骰值 | 概率 | 等级 | 方向 |
|------|------|------|------|
| 0-14 | 15% | 顺风顺水 | 顺风·加速·赠益 |
| 15-34 | 20% | 偶遇友善 | 搭把手·友善同行 |
| 35-69 | 35% | 平淡无事 | 正常推进 |
| 70-79 | 10% | 天气变化 | 小幅消耗 |
| 80-86 | 7% | 小波折 | 耽搁·需费口舌或小钱 |
| 87-92 | 6% | 旅途异象 | 从已有钩子推进·尽量不留新疑点 |
| 93-96 | 4% | 麻烦上门 | 从已有钩子推进·需应对 |
| 97-99 | 3% | 危险 | 强制处理·消耗资源 |

## 混乱值修正（加法）

最终骰值 = 骰值 + 混乱值 × 0.25

| 混乱值 | 修正值 | 效果 |
|--------|--------|------|
| 0 | +0 | 无偏移 |
| 30 | +8 | 轻微 |
| 50 | +13 | 中性事件开始偏向不顺 |
| 70 | +18 | 不顺倾向明显 |
| 85 | +21 | 几乎所有事件都偏不顺 |
| 100 | +25 | 最糟情况 |
