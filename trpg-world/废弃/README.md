### 日常骰子事件.md / 旅途骰子事件.md（2026-09-17 停用）

性质：内容生成型随机——从概率表重新采样，用来"无中生有"制造事件，不放映世界状态。

停用原因：
- 世界内容正在变密（每个基础设施将接入小游戏 / 养成联动；每个地点将有对应的
  `place_notes` / 定时事件，如「xx 广场 xx 时有烟火演出」），不再需要靠随机数填充空白。
- 内容一密，随机事件就会与真实内容打架（广场正在放烟火，骰子却回"平淡无事"），
  从"填充"变成"噪声"。
- 设计方向是让各系统状态互相作用产生涌现（地点事件 × NPC 日程 × 养成 × 时间/天气），
  而不是独立于状态的一张事件表。

保留了代码：`trpg-server/tools/event_dice.py`；已进 `registry._DISABLED`
（不下发给 LLM、不可被调用）。设 `TRPG_EVENT_DICE=1` 可临时启用（回滚 / 对照）。
