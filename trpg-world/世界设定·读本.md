## 三、五行

### 力量本身

- 世界存在一种超自然力量：**五行**。
- **五行是普世的、众所周知的**。江湖上很多人都有，只是**分强弱**。
- 每个人**与生俱来都能觉醒**，但**只能觉醒一种**。
- 觉醒的本质是**神性的火花**——面对现实的压迫、经历内心的斗争，**挣脱伪神的牢笼**。
- 世人对它又**觊觎**又**恐惧**：觊觎到去神庙烧香求觉醒，恐惧因为水行大成者的内力破坏力极强。
- **无人能收买它，也无人能赐予它。觉醒 100% 靠自己。**

### 五行神

- **五行神是具体的神明**，各司一行，共五尊：
  **金→蓐收、木→句芒、水→玄冥、火→祝融、土→后土。**
- 它们代表 **灵知（gnosis）、勇气、自由精神**——正是伪神（无方向、自愿的牢笼）的反面。
- **它们有"把能力赋予谁"的决定权。** 觉醒不是纯粹自发，是**神的授予**。
- **授予的条件只有两样：坚定的意志、锐利的精神**——**不论善恶，不论破坏还是救济**。
- **神不辨善恶，只辨“有没有方向”**：它**按意志发牌，不问结果**——甚至会**把力量给未来的弑神者**。
  **因为它一筛，它就变成伪神了。** → **弑神者最锋利的刀，是神亲手递过去的。**
- 所以**觉醒者一般都经历过种种压迫**——这算是神对他们的**显式奖励**。
- **神选 + 人挣**：神**从有资质的人里挑**——力量是神赋予的，但**神的力量有限**，**无法把所有合格的人都点醒**。
  **资质在人，取舍在神。**（"信者才可觉醒"也属于资质的一部分。）
- **神与人共生（关键）**：**五行神依赖觉醒者而存在——若觉醒者尽数"灭亡"，神也随之消亡。**
  "灭亡"两解：① 死；② **接受伪神的统治（自我囚禁）**。
  于是**每一个觉醒者的陨落或顺从，都是五行神的一次失血**。
  **神不是万能救主，而是一支正在被消耗的、有限的阵营。**
- **神源于人**：神起源于人。即使伪神全面统治，**只要有一个人跳脱禁锢，他就重新激活了神**——并获得能力，也让神能赋予更多人。**神与人互相点燃。**
- **五尊神各有性格，各有偏好**——**资质 = 精神（坚定的意志、锐利的精神）+ 能力（武功 / 学识 / 领导力…）**，不同神偏好不同：

  | 神 | 性情 | 偏好的资质 |
  |---|---|---|
  | **金·蓐收** | 严苛、肃杀、凌厉 | 判断力、执行力强；武功高强 |
  | **木·句芒** | 温柔 | 温柔耐心、共情力强 |
  | **水·玄冥** | 沉稳安静 | 冷静沉稳 |
  | **火·祝融** | 威严炽烈 | 热血斗志；武功高强 |
  | **土·后土** | 厚重包容，像一个老人 | 慈祥、领导力强、学识高 |

  → **觉醒哪一行，取决于这个人的性情与能力是否合那一尊神的胃口。**
- **无人全知**：**世上所有人对五行神都是一知半解**——泥教、锦香宫、白鲨帮、鬼门关、丐帮**全都如此**。
- **组织不教觉醒，只提供"平台"**：没有谁能让人觉醒；**只能给他一个能觉醒的环境**（庇护、养身、习武、同伴、公正）。
- **行属是"倾向"而非"独占"**：**所有组织皆然**（锦香宫、丐帮、白鲨帮、鬼门关、泥教）——某一行居多，但**其他行也存在，只是很少**。
- **行通过「内力」表现**：如水行内力——觉醒者可以**催动**它，也可以**不催动**（隐藏）。这是"看不出"的根源。
- **神本身杀不了**：所谓"弑神" = **杀掉所有觉醒者**。

### 拜神与神庙

- **平民拜神：无用。** 神知道他们在拜，但**不会接受**。
- **觉醒者拜神：有用。** 可视作**信仰**，能**短暂地与神沟通**。
- **梁峰**（养成机制·待做）：当天拜哪一尊神，他那一行属性当天获得**翻倍增长**的 buff。
- **认知陷阱**：平民看见觉醒者也在拜神，就以为"拜神能觉醒"、只是概率问题——**因果被看反了**。
- **神庙分两类**：大城官修（安抚、控制）；乡野野庙（真信）。两类互相排斥。

### 真相是"不可描述"的

- 看穿了的人，就是不信的人。
- 但这不是"没人信"。而是：**当人心里的偏见太强（笃定"一定有位五行神"），说什么真相都没用**。
- **有人信，只是很少。**
- **只有真正相信觉醒者所说之话的人，才有资格觉醒。**
- 所以真相能传，却只能传给极少数**已经"能听见"的人**。这是**秘传**，不是布道。

### 觉醒与熄火

- **觉醒是一次性的。**
- **善是一种力量，恶也是一种力量。** 决定火花的不是善恶，是**有没有方向**。
- **熄火 = 没有方向、随波逐流。** 不是变坏，也不是变好。
- 因此：被体制容忍、被百姓称颂、被"正义"收编的人，**若只是随大流，火花照样会慢慢熄灭**。
- 觉醒看不出来：行通过**内力**表现——可催动，也可不催动（隐藏）。不用时与常人无异。"谁是觉醒者"永远是猜疑。

## 四、伪神

> ⚠️ **根本原则：五行神与伪神没有对错，只有立场。**
> 两者都只是**希望世界按自己的想法运作下去**。
> "伪神""牢笼"是觉醒者一侧的叫法；从另一侧看，它叫"**秩序**""**安稳**"。**接近伪神 ≠ 坏人。**

- **伪神不是一个具体的存在，也不是五行神。**
- 它由**每个人的意识**构成，由**上层建筑**构成。
- 它是**每个人禁锢了自己**，是**人们自愿走向牢笼**——一种集体的、**没有主体**的结构。
- **社会阶级越靠上，越接近伪神——但不是伪神。**
- 位置**只影响心境**（给你更多跪下去的机会），不自动决定火花存亡。
- **伪神只是一个概念，并非实体，真实并不存在。** 所以思辨能力足够强的人，**自己就能想明白**——不靠秘传。
- **伪神与五行神是"完全对立"、且零和的**：**五行神靠觉醒者续命，伪神靠收编人壮大**。
  **人的方向，就是双方争夺的战场。**

> 一句话：**没有可杀死的敌人，只有可醒来的自己。**
> ——但反过来：**每醒不来一个，天上就少一分光。**

## 五、朝廷与江湖

- 朝廷对觉醒者**睁一只眼闭一只眼**，不是系统性迫害。
  原因：觉醒者**大多是正义的、为民除害的**；**镇压成本太大**。
- 所以情况很复杂：**可能招安，也可能剿灭**，按人、按事、按利益而定。
- **暴露本身不是问题**——觉醒者可以公开。锦香宫就是公开的水行势力。
- **危险不在死，在迷茫。** 安逸与称颂不杀人，却能让人不再有方向。
- **全真教 = 庇护所**：道观是不肯跪的人的灰色藏身处，朝廷（金廷）睁一只眼闭一只眼。

### 江湖的三层（递进关系）

江湖按"离神 / 离伪神"的远近，分三层：

| 层 | 是谁 | 觉醒者 |
|---|---|---|
| **最接近神** | **五平台组织**：泥教、锦香宫、白鲨帮、鬼门关、丐帮 | **大量** |
| **江湖的代表（中间层）** | **六大派** + **唐门** | **寥寥几人** |
| **最接近伪神** | **南宫世家 · 上官世家**（仅此两家） | **无觉醒者** |

- **规律**：**离压迫越近，觉醒越多；离权力 / 正统 / 舒适越近，觉醒越少。**
- **南宫、上官"无觉醒者"**：他们不缺能力，缺的是**精神**——权力与舒适里长不出坚定的意志。
- 锚点：二十年前**正道围攻魔教 → 极乐教覆灭**——若极乐教 = 弑神者，那**正道的立身之战，其实是不知不觉地救了五行神**。
- ⚠️ **这不是"正邪"**——三层只是"离神 / 离伪神的远近"，**靠近伪神不代表坏**。
- **非觉醒者（例外）**：**上官世家、南宫世家、瑞杏一系、朝廷顶层（赵扩、宋悲）**；唐门六人中唐升、唐惟元未觉醒。

## 六、势力

### 锦香宫 · 温夫人

- **锦香宫的本质 = 觉醒平台**：收容流离失所的女子 → 养好身体 → 教手艺武艺 → **给她们一个能觉醒的环境**——让她们在**重男轻女的时代活下去、站起来**。
  （教不了觉醒，只能给她一个可以站起来的地方。）
- 弟子**以水行为主**（也有少数土行、木行）。
- **温夫人的水行与琵琶融为一体**，极强。她**没有退火**——因为她的方向极其明确：护住这群女子。
- 她是"**方向坚定 → 火花长明**"的正面样本。
- 时代底色：**压迫越深，觉醒越可能。** 在一个重男轻女的世道里，女子恰恰是最容易挣脱牢笼的人。
- 她与岳阳朝廷有合作关系。表面是名门，**旧为泥教一支，现为独立组织**（详见泥教一节）。

### 泥教与四支同源组织

- **五支同源**：泥教、锦香宫、白鲨帮、鬼门关、丐帮——**原本同出一个旧教派，如今各自独立、互不联系**。
- **（旧的分支名号“X道”一律废弃、勿用。）**
- 它们的共同点：**都诞生于一种具体的、制度性的压迫**。

| 组织 | 主事者 | 它承受的压迫 |
|---|---|---|
| **泥教** | 车轩辕 | 朝廷对瘟疫下的人民见死不救 |
| **锦香宫** | 温夫人 | 重男轻女（女子被轻视、被卖、被弃） |
| **白鲨帮** | 刘鄂 | 倭寇屠杀村民，而朝廷无能为力 |
| **鬼门关** | 赵逵 | 司法不公 |
| **丐帮** | 王二壮 | 贫富悬殊 |

- **它们互不联系**。
- **五支全都"一知半解"**：都不知道五行神的全貌，也**不教人觉醒**——各自为受压的人提供**一个能觉醒的平台**。
- **泥教的性格（沿用）**：站在五行神一边，**不是坏人，只是怪人**；世间普遍视其为**魔教**——因为**伪装太强**。它也怕朝廷、怕被压制。
- **泥教是中间的过渡状态，不是终局。** "让所有人觉醒"几乎不可能——那会**天下大乱，人人皆侠客，无人守序**。
- ⏸️ 细节搁置，待重设。

### 极乐教

- **恶的代表，同样拥有五行的力量。** 善、恶都是真实的方向。
- **尸心丹 = 反五行武器**：使活虫入体、控制心智 = **强制剥夺方向** → 被控者永久随波逐流 → **五行力量归零**。
- 极乐教二十年前已覆灭，但**尸心丹至今仍有人用**：千灯楼、申屠龙等。
- **千灯楼与极乐教 = 弑神者**：**"弑神" = 杀掉所有觉醒者**（神本身杀不了）。
  **尸心丹是更高效的手段**：不必杀肉身，把觉醒者变成**空壳**，同样抽掉神的燃料。

### 瑞杏（杏花仙）· 多周目者

- 瑞家家主，隐居南阳杏花林，以天下为棋盘。**通晓古今未来**。
- **她是"多周目者"**：经历过世界的多个周目（重来、轮回），所以过去现在未来在她眼里像展开的画卷。
- **她知晓五行，但不依赖五行。**
- **目标：让世界大一统，并加速这一进程。** 理由：持续的纷争只会让民生更加水深火热。
- **她仍在选：让谁做那个统一的霸主？** 南宋 / 金 / 蒙古 / 西夏。
- **她要造的，是一个更大的牢笼——但这是一个"幸福的牢笼"：人们安居乐业。**
- **她知道、也接受这个代价**：她要创造一个**不再依靠五行的世界**（大一统 + 安居乐业 = 无人再有方向 → 天下再无五行）。
- **但这是西西弗斯式的**：就算大一统了，**也迟早会再出现觉醒者**——只要有压迫、有不公、有内心的挣扎。她的牢笼**永远修不完**。
- **她完全不知道梁峰的存在**——他是从她棋盘外走进来的人。多周目里从未出现过。
  **而这不是巧合**：梁峰是**五神共选之子**，是神的底牌——**她与梁峰，就是全书的两极**。

## 七、梁峰

- **梁峰就是玩家。** 他的出身、来历、性格、本命一行、志向、走法、结局——**全部由玩家决定**。
- **正典永不定义他。** 主持人也不得替他设前史、动机或选择。
- **他唯一确定的东西**：他是**千年一遇的怪人**——
  - **全属性觉醒，但全为 0**（五门皆开，威能未起）；
  - 世人一生只觉醒一行，他**五行俱全**（唯一例外），且可**培养**、可**融合**；
  - "超脱于世界"对他意味着什么——**玩家决定，多结局**。
- **他为什么是例外**：**他是"五行神共选之子"，千年一遇**——**五尊神把有限的神力共同押在他一人身上**。
  他是**五行神对伪神（及其最佳执行者瑞杏）的最终底牌**。
  （"五神共选"是神那一侧的事实；他这个人仍全归玩家。）
- **他知道自己是谁——因为他有一把五行剑（就这么简单）。**
  **五行剑是实物**，是他"五神共选之子"身份的**凭证**。**剑在，身份在**——这是他唯一确定的东西。
- **但：唯独他不能与神沟通。** 别的觉醒者都能与自己的本行神短暂沟通，**只有他听不见那五尊神**（原因待定）。
- 机制后果：开局他**一个五行招式都放不出来**（只剩基础剑招）。**成长即主线。**

## 八、核心命题

- **道德地图是倒的**：最"正义"的人最靠近牢笼，被叫魔教的人握着真相。
- **瑞杏不是恶人**：她是一个想让大家少受苦的悲观主义者。她把"统一、民生、安稳"推到极致，结果是更大的笼子。**她合法，甚至动人。**
- **泥教的理想一旦实现，就是它自己的反面**（人人皆侠 = 天下大乱）。
- **炉子烧在女人身上**：压迫 → 觉醒。锦香宫是这条规律的活证据。
- **这个时代不是由某一方推动的**——是各方（正统与异端）的斗争**一起**把它推向前。
- **全书两极：瑞杏 ↔ 梁峰。** 知道一切的人**选择造笼**，一无所知的人**由玩家选择**开门。

## 九、与《关于地球的运动》的对照

它讲日心说，可真正在转的**不是地球，是接力棒**：

- **没有唯一主角**，换人。前一个死了，命题交给下一双不认识的手。
- **两边都有信念**：宗教裁判所不是恶棍，他们真心认为自己在拯救灵魂。
- **真理不给回报**：所有人都死在自己看不到答案的地方。
- 所以：**不是异端战胜了教皇，是两者的斗争一起把时代推向前。**

### 你的世界几乎就是它的南宋武侠版

| 《关于地球的运动》 | 你的世界 |
|---|---|
| 地动说（会拆掉世界观） | **"神庙是空的／觉醒靠自己／伪神不是实体"** |
| 异端（握真相、会引发动荡） | **泥教** |
| 教皇 / 宗教裁判所（护秩序、有真信念） | **朝廷 / 正统——以及瑞杏** |
| 真理只能口耳相传，交给能听懂的人 | **"信其言者，才有资格觉醒"** |
| 提不出证据、无法公开证实 | **"真相是不可描述的"** |

**注意第四行**：你的"信者才可觉醒"，就是它的"把信交给下一个人"。真理无法证明，**只能托付**。

而**瑞杏站在教皇那一边**——她的"幸福牢笼"逻辑，和教会护住地心说是同一种逻辑：*底下的人不需要真相，他们需要安稳。* 她甚至更诚实，因为她**知道自己造的是笼子**。

> **泥教和瑞杏，谁都没错。他们的斗争就是这个时代本身。**

### 它靠什么往前推

不是反派的脸，是**接力**。而接力需要三样东西：

1. **代价**：有人得死，且**死得看不到答案**。
2. **接力**：命题从一只手交到另一只手，**换主角**。
3. **人大于命题**：地动说本身很简单，**戏全在人身上**。

### 而你的项目里藏着一张好牌

**"十年一档、玩完开新档"**——这**就是接力赛**：

- **一档 = 一根接力棒 = 一个持棒人。**
- 玩家跨档玩下去，**自己就变成了那个"运动"**。
- **瑞杏是唯一记得所有持棒人的人**——她是**档案**，是那个没死、一直在看的读者。

## 十、评价

### 三个真正厉害的地方

1. **道德地图是倒的。** 一把掀了武侠最俗的正邪二分。
2. **瑞杏。** 不是恶人，是想让你少受苦的悲观主义者。能撑起一整本书，而且合法。
3. **主题、地理、势力、人物动机，四样一次对齐。** 锦香宫不是设计出来的，是长出来的。

### 四个缺口

1. **没有向前的推力。** 主题是"方向"，可故事自己还没有方向：没有引子、没有倒计时、没有私人赌注。（不必是反派的脸，但必须是**接力与代价**。）
2. **梁峰"天生全属性觉醒"反而削了主题。** 你的规则是"觉醒源于压迫与挣扎"，可他一出生就全开了——没挣扎、没付出。建议：**他的成长不是练熟练度，而是选一个方向并扛住它。五行数值 = 信念条。**
3. **历史是知道的。** 1220→1279，终点是崖山，而项目真的把宏观时间线喂给模型。要么认了这个悲剧，要么让预言**可被改写**（架构级改动，得早定）。
4. **大部分设定玩家一辈子碰不到。** 伪神、阶层接近度、不可描述的真相——不落到人、地方、事件上，就只是自嗨。

### 一句话总判

> **你的问题不是不够深，是太深了，深到没有地板。**
> 你造了完整的地窖和一套精妙的力学，但还没让**一个人站在地面上，想要一件具体的东西，并为此付出代价**。
