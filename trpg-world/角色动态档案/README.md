# 角色动态档案

分两个目录（世界推演的对象名单）：

- **`活跃/`**：正在被世界推演的人物。每游戏日由小模型采样推进
  （地点 / 事件类型 / 顺利度）。**世界推演只扫这个目录**——谁在这里，谁就被推演。
- **`不活跃/`**：已淘汰的人物（内容已进 chroma）。

## 一个 `<人物名>.md` 里放什么

该人物的**近记忆**：记忆 / 感情 / 认知。例如：

```md
# 上官萤（活跃）

- 1220-01-16 福州 · 营生 · 不顺
- 1220-01-17 福州 · 营生 · 平
```

（`世界状态.json` 里另存结构化的「人物线程」；本文件是给大模型读的近记忆文本。）
