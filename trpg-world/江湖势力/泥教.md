# 泥教与四支同源组织

> 2026-09-18 修订：旧泥教的多支结构已解散——「泥教」如今只指车轩辕这一支；其余四支各自独立、互不联系。（旧的分支名号已废弃，勿再使用。）

接替极乐教崛起的教派，被视为「新魔教」。总坛位于六道峡。

- 命名含义：一谓人间即是泥沼，苍生深陷苦海；二谓六道峡挖出泥浆温泉，教众喜泡泥巴浴
- 本质：不坏——只是怪。特立独行，不按江湖规矩出牌。被视为魔教，根源不在作恶，在「非我族类，其心必异」的偏见
- 整体立场：与杏花仙（瑞杏）敌对。江湖视其为魔教，但其行事并非全然邪恶
- 公开程度：身份未公开，仍为暗中活动。车轩辕坐镇六道峡

## 同源五支

原本同出旧泥教，如今各自独立、互不联系。它们的共同点：都诞生于一种具体的、制度性的压迫——是最典型的"经历压迫"的组织。

| 组织 | 主事者 | 承受的压迫 |
|---|---|---|
| 泥教 | 车轩辕（医者·六道峡） | 朝廷对瘟疫下的人民见死不救 |
| 锦香宫 | 温夫人（苏迎香） | 重男轻女——纠正世人对「女流」的蔑视 |
| 白鲨帮 | 刘鄂（东海鬼岛） | 倭寇屠杀村民，而朝廷无能为力 |
| 鬼门关 | 赵逵 | 司法不公——以私刑诛杀官府办不了的人 |
| 丐帮 | 王二壮（王春临） | 贫富悬殊——底层挣扎的人 |
