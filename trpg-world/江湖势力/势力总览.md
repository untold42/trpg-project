# 势力范围

## 蜀中区域

### 唐门（眉山）

| 项目 | 内容 |
|------|------|
| 核心 | 眉山 · 唐家大院 |
| 辐射范围 | 成都平原、蜀中盆地全域。出剑门关后影响力快速衰减 |
| 影响方式 | 暗器与毒药生意覆盖川内武林；外姓弟子偶有出蜀行走 |
| 控制力 | 蜀中强，出蜀弱。唐门暗器虽名震江湖，但门人极少离蜀 |
| 备注 | 地产大多已变卖，仅余祖宅，财力不比从前 |
| 辐射等级 | 蜀中4 · 出蜀1 |
| 活跃倾向 | 低调自守，不惹事但也不怕事。蜀中地界上有人动唐门的人，必追究 |

| 项目 | 内容 |
|------|------|
| 核心 | 终南山 |

|------|------|
