## 〇、一句话

以南宋真实历史为底、允许超自然（五行）的架空世界；有真实的民生、江湖与政权纷争。
核心张力两根：诺斯替主义（觉醒 / 伪神 / 牢笼，落点是"真实 vs 无方向"）× 侠客与朝廷。

## 一、五行 【已定】

- 世界存在一种五行超自然力量。五行是普世的、众所周知的——江湖上很多人拥有，只是分强弱。
- 每个人与生俱来都能觉醒，但只能觉醒一种。（梁峰是唯一例外，见 §七）
- 觉醒的本质是神性的火花：对世界给出自己的答案（灵知）——是挣脱伪神牢笼的结果。
- 世人对它的态度是矛盾的：觊觎（去五行神庙祭祀，企图某天觉醒）与恐惧（力量太强——水行大成者的内力破坏力极强）并存。

### 五行神 【已定】

- 五行神是具体的神明，各司一行，共五尊：金=蓐收、木=句芒、水=玄冥、火=祝融、土=后土。
- 它们代表 灵知（gnosis）、勇气、自由精神——正是伪神（无方向 / 自愿的牢笼）的反面。
- 它们有"把能力赋予谁"的决定权。 觉醒不是纯粹自发，是神的授予。
- 授予的唯一条件：灵知（独特的思考 + 坚韧的意志）——不论善恶，不论破坏还是救济。
- 神不辨善恶，只辨“有没有灵知”（2026-09-21 修订）：它按灵知发牌，不问结果——甚至会把力量给未来的弑神者。
  - 为何？因为它一筛，它就变成伪神了。 审视、分类、只给“该给的人”是伪神的做法；五行神只认意志。
  - → 弑神者最锋利的刀，是神亲手递过去的。而神知道，还是递了——不递，它就输了自己。
- （2026-09-21 修订）觉醒者什么人都有：苦难非必要非充分、且不可量化——不受苦也能觉醒，受尽苦难也可能不觉醒。压迫只提供问题，答案得自己给。
- 无配额：神一次性授予，不“挑人”、不分名额；能不能接通只看有没有灵知，以及合不合那尊神的胃口。授予之后，力量便归个人，能练到何种地步全看自己。
- 神与人的共生（关键 · 2026-09-18 新增）：五行神依赖觉醒者而存在——若觉醒者尽数"灭亡"，五行神也随之消亡。
  - "灭亡"两解：① 死；② 接受伪神的统治（自我囚禁）——世上再没有符合资质的人。
  - 所以：每一个觉醒者的陨落或顺从，都是五行神的一次失血；神不是万能救主，而是一支正在被消耗的、有限的阵营。
  - 神本身杀不了：所谓"弑神" = 杀掉所有觉醒者（见 §五）。
- 神源于人（关键 · 2026-09-18 新增）：五行神起源于人。即使在伪神的全面统治下，只要有一个人跳脱禁锢，他就重新激活了神——他既获得能力，也让神有力量去赋予更多觉醒者。
  → 神与人不是"赐予—接受"，而是互相点燃。
- 五尊神各有性格，各有偏好（关键 · 2026-09-18）——资质 = 精神（坚定的意志、锐利的精神）+ 能力（武功 / 学识 / 领导力…），不同神偏好不同：

  | 神 | 性情 | 认得出的灵知 |
  |---|---|---|
  | 金·蓐收 | 肃杀凌厉 | 判断力、执行力、武功 |
  | 木·句芒 | 温柔活泼 | 温柔、耐心、共情 |
  | 水·玄冥 | 神秘安静 | 冷静、沉着 |
  | 火·祝融 | 威严炽烈 | 热血、豪放、武功 |
  | 土·后土 | 厚重包容 | 慈爱、领导力、学识 |

  → 觉醒哪一行，取决于这个人的性情与能力是否合那一尊神的胃口。
- 无人全知（关键）：世上所有人对五行神都只是一知半解——泥教、锦香宫、白鲨帮、鬼门关、丐帮全都如此。
- 组织教「思想」和「技艺」，但不教灵知：听懂了不等于它成了你的，全靠个人修为。
- 组织的行属是"倾向"而非"独占"：所有组织皆然（锦香宫、丐帮、白鲨帮、鬼门关、泥教）——某一行居多，但其他行也存在，只是很少。压迫的类型影响人群，不决定行属。
- 行通过「内力」表现（关键）：如水行内力——觉醒者可以催动它（外放），也可以不催动（隐藏）。
  → 这是"觉醒完全看不出"的机制根源（见 §三）。

### 拜神 【2026-09-18 修订：旧说"拜了没用"不完全对】

- 平民拜神：无用。 神知道他们在拜，但不会接受。
- 觉醒者拜神：有用。 可视作信仰，能短暂地与神沟通。
- 梁峰（养成机制·待做）：当天拜哪一尊神，他那一行属性当天获得翻倍增长的 buff（见 §十）。
- 认知陷阱由此产生：平民看见觉醒者也在拜神，便以为"拜神能觉醒"，只是概率问题——因果被看反了。

### 神庙

- 分两类，且互相排斥：
  - 大城官修：官府出资，功能是安抚 / 控制——把"想觉醒"那股劲儿引成磕头烧香。
  - 乡野野庙：百姓自凑，是绝望里的真信。
  - 于是官修神庙 = 伪神的安抚装置（求不到，正因为求不到才安全）。

#### 五行神庙（2026-09-19 定）

- 五行神庙与普通神庙（城隍庙 / 土地庙 / 寺 / 观 / 祠）严格分开：只有五行神庙供奉五行神，
  拜对了才有用（当日该行熟练度成长 ×2）；普通神庙不参与养成，只是叙事。
- 五座神各主一行：祝融庙（火）/ 玄冥庙（水）/ 句芒庙（木）/ 蓐收庙（金）/ 后土庙（土）。
- 一座城市（城内 + 城外）合计最多 10 所五行神庙（世界事实，由地图生成保证）：
  每行至多 2 所——城内官修 1 所 + 城外野庙 1 所。
  - 例（岳阳）：城内 5（每行 1）+ 城外 4 + 锦香宫内 1 所玄冥庙 = 10。
- 锦香宫内置一所玄冥庙（宫供奉水行，故立于院内；此处计入岳阳的 10 所名额）。
- 机制见 `trpg-server/facilities.json`（五行神庙→当日该行成长 buff）与 `tools/核心/growth.py`（养成管道）。

### 认知陷阱：真相是"不可描述"的

- 看穿了的人就是不信的人；五行力量确实存在，只是不靠香火得来。
- 这不是"没人信"，而是：当人心里的偏见太强（以为烧香就能觉醒），说什么真相都没用。
- 但有人信，只是很少——只有真正相信觉醒者所说之话的人，才有资格觉醒。
- （→ 真相能传，却只能传给极少数已经"能听见"的人；这是 gnosis 式的秘传，不是公开布道。）
- （与"神有决定权"的关系已理清：资质在人，取舍在神——见上。）

### 锦香宫与温夫人：一个"觉醒"的样本 【已定】

- 锦香宫的本质 = 五支组织之一（旧泥教的一支·现独立组织，见 §五）：收容流离失所的女子 → 养好身体 → 教手艺/武艺与一套女性思想 → 给她一个能自己站起来的地方（灵知教不了，能不能觉醒全看她自己）——让她们在重男轻女的时代活下去、站起来。
- 温夫人水行极强（与琵琶融为一体），且没有退火：她的方向极其明确（护住这群女子）。
  → 她是"方向坚定 → 火花长明"的正面样本，与"安逸收编 → 熄火"正好对照（§三）。
  （现状正典已写她"琵琶功/音波功极高""琵琶离身则无战力"，五行是给这份武力补上来源。）
- 时代底色：在一个重男轻女的世道里，锦香宫把另一种答案摆在女子面前——能不能成为她自己的，看她自己（苦难非成因、灵知不可教，见 §三）。

## 二、伪神 【已定】

> ⚠️ 根本原则：五行神与伪神没有对错，只有立场。
> 它们都只是希望世界按自己的想法运作下去。
> "伪神""牢笼"是觉醒者一侧的叫法；从另一侧看，它叫"秩序""安稳"。
> 接近伪神 ≠ 坏人。

- 伪神不是一个具体的存在，也不是五行神。
- 伪神由每个人的意识构成、由上层建筑构成。
- 它是每个人禁锢了自己、是人们自愿走向牢笼——一种集体性的、无主体的结构。
- 社会阶级越处于上层的人，越接近伪神——但不是伪神。（位置只影响心境，不自动定生死，见 §三）
- 五行神与伪神是对立的（即：五行神不是伪神）。
- 伪神是一个概念，并非实体——真实并不存在；因此思辨能力足够强的人，可以自己意识到它（不靠秘传）。
- 五行神与伪神是"完全对立"、且零和的：五行神靠觉醒者续命，伪神靠收编人壮大。人的方向，就是双方争夺的战场（见 §一）。

> 【助手理解，待用户确认】这套设定把诺斯替的"巨匠造物主"与"上层建筑"焊在了一起：
> 没有可杀死的敌人，只有可醒来的自己。反派因此是弥散的（朝廷 / 礼教 / 士大夫 / 乡绅，
> 乃至已觉醒却又不肯再斗争的人）。此理解若不符，请纠正。

## 三、觉醒机制 【2026-09-21 修订】

- 觉醒是一次性的（五行俱全的两人除外，见 §七）。
- 觉醒的成因（修订）：灵知——对世界的独特思考 + 把它变成行动的坚韧意志。
  压迫不再是成因（苦难非必要、非充分、不可量化）：它只提供问题，答案得自己给。
- 力量的方向性（核心）：善是一种力量，恶也是一种力量——决定火花的不是善恶，而是有没有灵知。
- 熄火 = 你的思考不再是你的（不是"变坏"，也不是"变好"）。两条路：① 自弃（累了，不再想）；② 被渗透（别人替你把答案回答掉，你接受了）。
  → 因此被体制容忍、被民众称颂、被"正义"收编的人，若不再自己回答，火花照样渐灭。
- 觉醒的判定看心境，不看位置：地位越高只影响心境（权力让人不必自己回答），不自动决定火花存亡。
- 可见性（修订）：灵知看不见，所以力量是唯一的可见证据。小招式可催动、可不催动（隐藏）；但力量越大越藏不住——一旦呼风唤雨，满城皆知。
  - 【待确认】主动动用时是否仍可完全隐藏（连动手都看不出），还是出手即露行迹？见 §八。

## 四、侠客与朝廷 【已定】

### 江湖的三层（递进关系）【已定 · 2026-09-18】

江湖按"离神 / 离伪神"的远近，分三层：

| 层 | 是谁 | 位置 | 觉醒者 |
|---|---|---|---|
| 最接近神 | 五支组织：泥教、锦香宫、白鲨帮、鬼门关、丐帮 | 教新的、未被承认的思想 | 大半 |
| 江湖的代表（中间层） | 六大派（全真/少林/崆峒/青城/峨嵋/点苍）+ 唐门 | 教正统、现成的思想（背下来就行） | 寥寥几人 |
| 最接近伪神 | 南宫世家 · 上官世家（三大世家中近伪神的两家） | 答案由别人提供（礼制/利益/体面） | 无觉醒者 |

- 规律：离灵知越近，觉醒越多；离现成答案越近，觉醒越少（苦难不是成因，见 §三）。
- 南宫、上官"无觉醒者"：它们不缺能力（武功/学识/领导力），缺的是自己的答案——权力与体面让人不必自己回答。
- 统称「五支组织」。
- 唐门同属三大世家，却归入中间层（2026-09-18 修订）；与朝廷作对的旧作风不变（见 §八·15）。
- 六大派只有寥寥几人觉醒：他们是江湖的主流，也是"规矩"的载体。
- 正典锚点：二十年前正道围攻魔教 → 极乐教覆灭——若极乐教 = 弑神者，那正道的立身之战，其实是不知不觉地救了五行神（他们至今不知道）。
- ⚠️ 注意：这不是"正邪"——三层只是"离神 / 离伪神的远近"，靠近伪神不代表坏（见 §二）。

- 定位：与 gnostic 主题并列的另一根张力（"侠以武犯禁"）。
- 朝廷态度：睁一只眼闭一只眼——不是系统性迫害。原因：
  - 觉醒者大部分是正义的、为民除害的；
  - 镇压成本太大。
- 因此情况很复杂：对觉醒者可能招安，也可能剿灭，按人、按事、按利益而定，没有一刀切。
- 暴露本身不是问题：觉醒者可以公开（如锦香宫就是公开的水行能力者势力），社会与之共存。
  → 危险不在死，在迷茫：安逸与称颂不杀人，却能让人不再有方向。
- 锦香宫与岳阳朝廷有合作关系（表面名门；旧泥教的一支，现为独立组织——双重身份，见 §五）。
- 全真教 = 庇护所：道观是"不肯跪的人"的灰色藏身处；朝廷（金廷）睁一只眼闭一只眼。

## 五、真相的一方：五支组织 【2026-09-21 定名】

- 五支同源：泥教、锦香宫、白鲨帮、鬼门关、丐帮——原本同出一个旧教派，如今各自独立、互不联系。
- ⚠️ 旧的分支名号（“X道”）一律废弃、勿再使用——它们会误导 GM。一律用组织本名。
- 它们的共同点：都诞生于回应一个具体的、制度性的问题（⚠️ 不是“压迫产生觉醒”——苦难非必要非充分，见 §三）。

| 组织 | 行属 | 所在 | 主事者 | 它回应的那个问题 |
|---|---|---|---|---|
| 泥教 | 木 | 襄阳 | 车轩辕（医者） | 朝廷对瘟疫下的人民见死不救 |
| 锦香宫 | 水 | 洞庭君山 | 温夫人 | 重男轻女（女子被轻视、被卖、被弃） |
| 白鲨帮 | 火 | 福州东海·鬼岛 | 刘鄂 | 倭寇屠杀村民，而朝廷无能为力 |
| 鬼门关 | 金 | 重庆府 | 赵逵 | 司法不公 |
| 丐帮 | 土 | 无总部 | 王二壮 | 贫富悬殊 |

- 它们互不联系（各行其道，无统属）。
- 五支全都“一知半解”：它们都不知道五行神的全貌。
- 它们教「思想」和「技艺」，但不教灵知：
  锦香宫教的是一套女性思想，外加剑术等应用；听懂了不等于它成了你的——全靠个人修为。
- 泥教的性格（沿用）：站在五行神（真实坚定的内心）一边，不是坏人，只是怪人；世间普遍视其为魔教——因为伪装太强。它也怕朝廷、怕被压制。
- ⏸️ 泥教的进一步细节仍搁置，待重设。

### 极乐教

- 恶的代表，同样拥有五行的力量。 善、恶都是真实的方向。
- 尸心丹 = 反五行武器：使活虫入体、控制心智 = 强制剥夺方向 → 被控者永久随波逐流 → 五行力量归零。
- 真正的弑神者是瑞杏（2026-09-21 定）；千灯楼 / 极乐教是另一条更粗劣的路子（尸心丹），见 §六。
  “弑神” = 杀掉 / 熄尽所有觉醒者——神本身杀不了，它只因觉醒者尽亡而消亡（见 §一）。
  - 尸心丹是更高效、也更隐毒的手段：不必杀肉身，把觉醒者变成空壳，同样抽掉神的燃料。
  - 因此弑神是西西弗斯式的：只要还剩一个够格的人跳脱，神就重新站起。
- 极乐教二十年前已覆灭，但尸心丹至今仍有人用：千灯楼、申屠龙等。

- 真实（善 / 恶皆可） ←→ 虚无（无方向）（见 §三）。
- 【沿用·待核】泥教 = 中间的过渡状态（不是终局）："让所有人觉醒"几乎不可能——那会天下大乱、人人皆侠。
