## 〇、一句话

以**南宋真实历史**为底、允许**超自然（五行）**的架空世界；有真实的民生、江湖与政权纷争。
核心张力两根：**诺斯替主义**（觉醒 / 伪神 / 牢笼，落点是"真实 vs 无方向"）× **侠客与朝廷**。

## 一、五行 【已定】

- 世界存在一种**五行**超自然力量。**五行是普世的、众所周知的**——江湖上很多人拥有，只是**分强弱**。
- 每个人**与生俱来都能觉醒**，但**只能觉醒一种**。（梁峰是唯一例外，见 §七）
- 觉醒的本质是**神性的火花**：面对**现实的压迫**、经历**内心的斗争**而觉醒——是**挣脱伪神牢笼**的结果。
- 世人对它的态度是矛盾的：**觊觎**（去五行神庙祭祀，企图某天觉醒）与**恐惧**（力量太强——**水行大成者的内力破坏力极强**）并存。

### 五行神 【已定 · 2026-09-18 修订】

> ⚠️ **修订**：旧版曾定「五行神无位格、不回应、不挑人、觉醒 100% 靠自己」——**已推翻**。现为**有位格的具体神明**。

- **五行神是具体的神明**，各司一行，共五尊：金=**蓐收**、木=**句芒**、水=**玄冥**、火=**祝融**、土=**后土**。
- 它们代表 **灵知（gnosis）、勇气、自由精神**——正是**伪神（无方向 / 自愿的牢笼）的反面**。
- **它们有"把能力赋予谁"的决定权。** 觉醒**不是纯粹自发**，是**神的授予**。
- **授予的条件只有两样：坚定的意志、锐利的精神**——**不论善恶，不论破坏还是救济**。
- **神不辨善恶，只辨“有没有方向”（关键 · 2026-09-18）**：它**按意志发牌，不问结果**——甚至会**把力量给未来的弑神者**。
  - **为何？因为它一筛，它就变成伪神了。** 审视、分类、只给“该给的人”是伪神的做法；**五行神只认意志**。
  - → **弑神者最锋利的刀，是神亲手递过去的。而神知道，还是递了**——**不递，它就输了自己。**
- 因此**觉醒者一般都经历过种种压迫**——这算是神对他们的**显式奖励**：在压迫里仍守住意志与精神的人，被选中。
- **神选 + 人挣（并存）**：五行神**从有资质的人里挑**——力量是神赋予的，但**神的力量有限**，**无法把所有符合资质的人都点醒**。
  - 所以：**人要够格**（坚定的意志 / 锐利的精神），**神再做取舍**（受神力总量所限）。
- **神与人的共生（关键 · 2026-09-18 新增）**：**五行神依赖觉醒者而存在——若觉醒者尽数"灭亡"，五行神也随之消亡。**
  - "灭亡"两解：① 死；② **接受伪神的统治（自我囚禁）**——世上再没有符合资质的人。
  - 所以：**每一个觉醒者的陨落或顺从，都是五行神的一次失血**；**神不是万能救主，而是一支正在被消耗的、有限的阵营**。
  - **神本身杀不了**：所谓"弑神" = **杀掉所有觉醒者**（见 §五）。
- **神源于人（关键 · 2026-09-18 新增）**：**五行神起源于人**。即使在伪神的全面统治下，**只要有一个人跳脱禁锢，他就重新激活了神**——他既获得能力，也让神**有力量去赋予更多觉醒者**。
  → 神与人不是"赐予—接受"，而是**互相点燃**。
- **五尊神各有性格，各有偏好（关键 · 2026-09-18）**——**资质 = 精神（坚定的意志、锐利的精神）+ 能力（武功 / 学识 / 领导力…）**，不同神偏好不同：

  | 神 | 性情 | 偏好的资质 |
  |---|---|---|
  | **金·蓐收** | 严苛、肃杀、凌厉 | **判断力、执行力强；武功高强** |
  | **木·句芒** | 温柔 | **温柔耐心、共情力强** |
  | **水·玄冥** | 沉稳安静 | **冷静沉稳** |
  | **火·祝融** | 威严炽烈 | **热血斗志；武功高强** |
  | **土·后土** | 厚重包容，像一个老人 | **慈祥、领导力强、学识高** |

  → **觉醒哪一行，取决于这个人的性情与能力是否合那一尊神的胃口。**
- **无人全知（关键）**：**世上所有人对五行神都只是一知半解**——泥教、锦香宫、白鲨帮、鬼门关、丐帮**全都如此**。
- **组织不教觉醒，只提供"平台"**：没有谁能让别人觉醒；**只能给他们一个能觉醒的环境**（庇护、养身、习武、同伴、公正）。
- **组织的行属是"倾向"而非"独占"**：**所有组织皆然**（锦香宫、丐帮、白鲨帮、鬼门关、泥教）——某一行居多，但**其他行也存在，只是很少**。压迫的类型影响人群，**不决定行属**。
- **行通过「内力」表现（关键）**：如水行内力——觉醒者可以**催动**它（外放），也可以**不催动**（隐藏）。
  → 这是"**觉醒完全看不出**"的机制根源（见 §三）。

### 拜神 【2026-09-18 修订：旧说"拜了没用"不完全对】

- **平民拜神：无用。** 神**知道他们在拜，但不会接受**。
- **觉醒者拜神：有用。** 可视作**信仰**，能**短暂地与神沟通**。
- **梁峰（养成机制·待做）**：**当天拜哪一尊神，他那一行属性当天获得翻倍增长的 buff**（见 §十）。
- **认知陷阱由此产生**：平民看见**觉醒者也在拜神**，便以为"拜神能觉醒"，只是**概率问题**——**因果被看反了**。

### 神庙

- **分两类，且互相排斥**：
  - **大城官修**：官府出资，功能是**安抚 / 控制**——把"想觉醒"那股劲儿引成磕头烧香。
  - **乡野野庙**：百姓自凑，是绝望里的**真信**。
  - 于是官修神庙 = **伪神的安抚装置**（求不到，正因为求不到才安全）。

### 认知陷阱：真相是"不可描述"的

- 看穿了的人**就是不信的人**；五行力量**确实存在**，只是**不靠香火得来**。
- 这不是"没人信"，而是：**当人心里的偏见太强（以为烧香就能觉醒），说什么真相都没用**。
- 但**有人信，只是很少**——**只有真正相信觉醒者所说之话的人，才有资格觉醒**。
- （→ 真相能传，却只能传给极少数**已经"能听见"的人**；这是 gnosis 式的**秘传**，不是公开布道。）
- （与"神有决定权"的关系已理清：**资质在人，取舍在神**——见上。）

### 锦香宫与温夫人：一个"觉醒"的样本 【已定】

- **锦香宫的本质 = 觉醒平台**（**旧泥教的一支·现独立组织**，见 §五）：收容流离失所的女子 → 养好身体 → 教手艺/武艺 → **给她们一个能觉醒的环境**（教不了觉醒，只能给她一个可以站起来的地方）——让她们在**重男轻女的时代活下去、站起来**。
- **温夫人水行极强（与琵琶融为一体），且没有退火**：她的方向极其明确（护住这群女子）。
  → 她是"**方向坚定 → 火花长明**"的**正面样本**，与"安逸收编 → 熄火"正好对照（§三）。
  （现状正典已写她"琵琶功/音波功极高""琵琶离身则无战力"，五行是给这份武力**补上来源**。）
- **时代底色**：**压迫越深，觉醒越可能**——在一个重男轻女的世道里，女子恰恰是最容易挣脱牢笼的人。锦香宫是这条规律的活证据。

## 二、伪神 【已定】

> ⚠️ **根本原则：五行神与伪神没有对错，只有立场。**
> 它们都只是**希望世界按自己的想法运作下去**。
> **"伪神""牢笼"是觉醒者一侧的叫法**；从另一侧看，它叫"**秩序**""**安稳**"。
> **接近伪神 ≠ 坏人。**

- **伪神不是一个具体的存在，也不是五行神。**
- 伪神由**每个人的意识**构成、由**上层建筑**构成。
- 它是**每个人禁锢了自己**、是**人们自愿走向牢笼**——一种**集体性的、无主体的结构**。
- **社会阶级越处于上层的人，越接近伪神——但不是伪神。**（位置**只影响心境**，不自动定生死，见 §三）
- **五行神与伪神是对立的**（即：五行神不是伪神）。
- **伪神是一个概念，并非实体——真实并不存在**；因此**思辨能力足够强的人，可以自己意识到它**（不靠秘传）。
- **五行神与伪神是"完全对立"、且零和的**：**五行神靠觉醒者续命，伪神靠收编人壮大**。人的方向，就是双方争夺的战场（见 §一）。

> 【助手理解，待用户确认】这套设定把诺斯替的"巨匠造物主"与"上层建筑"焊在了一起：
> **没有可杀死的敌人，只有可醒来的自己**。反派因此是弥散的（朝廷 / 礼教 / 士大夫 / 乡绅，
> 乃至已觉醒却又不肯再斗争的人）。此理解若不符，请纠正。

## 三、觉醒机制 【已定】

- **觉醒是一次性的。**
- 觉醒的成因：**现实的压迫 + 内心的斗争**（挣脱伪神牢笼）。
- **力量的方向性（核心）**：**善是一种力量，恶也是一种力量**——决定火花的**不是善恶，而是有没有方向**。
- **熄火 = 没有方向、随波逐流**（不是"变坏"，也不是"变好"）。
  → 因此被体制容忍、被民众称颂、被"正义"收编的人，若只是随大流，火花照样渐灭。
- **觉醒的判定看心境，不看位置**：地位越高**只影响**心境（给你更多跪下去的机会），**不自动决定**火花存亡。
- **可见性：完全看不出。** 觉醒者使用的是五行中某一行的**内力**（见 §一「行通过内力表现」），但他**可以选择催动或不催动**；平时与常人无异，"谁是觉醒者"永远是猜疑。
  - 【待确认】主动**动用**时是否仍可完全隐藏（连动手都看不出），还是出手即露行迹？见 §八。

## 四、侠客与朝廷 【已定】

### 江湖的三层（递进关系）【已定 · 2026-09-18】

江湖按"离神 / 离伪神"的远近，分三层：

| 层 | 是谁 | 位置 | 觉醒者 |
|---|---|---|---|
| **最接近神** | **五平台组织**：泥教、锦香宫、白鲨帮、鬼门关、丐帮 | 生在压迫里 | **大量** |
| **江湖的代表（中间层）** | **六大派**（全真/少林/崆峒/青城/峨嵋/点苍）+ **唐门** | 中间 | **寥寥几人** |
| **最接近伪神** | **南宫世家 · 上官世家**（仅此两家） | 靠权力、财富、正统 | **无觉醒者** |

- **规律**：**离压迫越近，觉醒越多；离权力 / 正统 / 舒适越近，觉醒越少。**
- **三大世家"无觉醒者"**只适用于**南宫、上官**：它们不缺能力（武功/学识/领导力），缺的是**精神**——**权力与舒适里长不出"坚定的意志、锐利的精神"**。
- **唐门归入中间层**（2026-09-18 修订）；它原先"不再与朝廷作对"的改动**是否仍需要，待确认**。
- **六大派只有寥寥几人觉醒**：他们是江湖的主流，也是"规矩"的载体。
- **正典锚点**：二十年前**正道围攻魔教 → 极乐教覆灭**——若极乐教 = 弑神者，那**正道的立身之战，其实是不知不觉地救了五行神**（他们至今不知道）。
- ⚠️ **注意：这不是"正邪"**——三层只是"离神 / 离伪神的远近"，**靠近伪神不代表坏**（见 §二）。

---

- 定位：与 gnostic 主题并列的另一根张力（"侠以武犯禁"）。
- **朝廷态度：睁一只眼闭一只眼**——不是系统性迫害。原因：
  - 觉醒者**大部分是正义的、为民除害的**；
  - **镇压成本太大**。
- 因此情况**很复杂**：对觉醒者**可能招安，也可能剿灭**，按人、按事、按利益而定，没有一刀切。
- **暴露本身不是问题**：觉醒者可以公开（如**锦香宫**就是公开的水行能力者势力），社会与之共存。
  → **危险不在死，在迷茫**：安逸与称颂不杀人，却能让人不再有方向。
- **锦香宫与岳阳朝廷有合作关系**（表面名门；旧泥教的一支，现为**独立组织**——双重身份，见 §五）。
- **全真教 = 庇护所**：道观是"不肯跪的人"的灰色藏身处；朝廷（金廷）睁一只眼闭一只眼。

## 五、真相的一方：泥教与四支同源组织 【已定 · 2026-09-18 修订】

- **五支同源**：泥教、锦香宫、白鲨帮、鬼门关、丐帮——**原本同出一个旧教派，如今各自独立、互不联系**。
- ⚠️ **旧的分支名号（“X道”）一律废弃、勿再使用**——它们会误导 GM。**一律用组织本名。**
- 它们的共同点：**都诞生于一种具体的、制度性的压迫**——是最典型的"经历压迫"的组织。

| 组织 | 主事者 | 它承受的压迫 |
|---|---|---|
| **泥教** | 车轩辕（六道峡·医者） | **朝廷对瘟疫下的人民见死不救** |
| **锦香宫** | 温夫人 | **重男轻女**（女子被轻视、被卖、被弃） |
| **白鲨帮** | 刘鄂 | **倭寇屠杀村民，而朝廷无能为力** |
| **鬼门关** | 赵逵 | **司法不公** |
| **丐帮** | 王二壮 | **贫富悬殊** |

- **它们互不联系**（各行其道，无统属）。
- **五支全都"一知半解"**：它们都不知道五行神的全貌，也**不教人觉醒**——只是各自为受压的人提供**一个能觉醒的平台**（见 §一）。
- **泥教的性格（沿用）**：站在**五行神（真实坚定的内心）一边**，**不是坏人，只是怪人**；世间普遍视其为**魔教**——因为**伪装太强**。它也**怕朝廷**、怕被压制。
- ⏸️ **泥教的进一步细节仍搁置**，待重设。

### 极乐教

- **恶的代表，同样拥有五行的力量。** 善、恶都是真实的方向。
- **尸心丹 = 反五行武器**：使活虫入体、控制心智 = **强制剥夺方向** → 被控者永久随波逐流 → **五行力量归零**。
- **千灯楼与极乐教 = 弑神者**：**"弑神" = 杀掉所有觉醒者**——**神本身杀不了**，它只因觉醒者尽亡而消亡（见 §一）。
  - **尸心丹是更高效、也更隐毒的手段**：不必杀肉身，把觉醒者变成**空壳**，同样抽掉神的燃料。
  - 因此弑神是**西西弗斯式**的：只要还剩一个够格的人跳脱，神就重新站起。
- 极乐教二十年前已覆灭，但**尸心丹至今仍有人用**：**千灯楼、申屠龙**等。

### 全局道德轴

- **真实（善 / 恶皆可） ←→ 虚无（无方向）**（见 §三）。
- **【沿用·待核】泥教 = 中间的过渡状态**（不是终局）："让所有人觉醒"几乎不可能——那会天下大乱、人人皆侠。

## 六、瑞杏（杏花仙）· 多周目者 【已定】

- **身份**：瑞家家主，隐居南阳杏花林，以天下为棋盘（正典：T0·绝顶，棋力，无武功；"通晓古今未来"）。
- **她是"多周目者"**：经历过世界的**多个周目**（重来 / 轮回），因此知道过去、现在与未来。
  - → 与项目自身的"**十年一档**"（玩完一档开新档，见 `TODO.md` §十五）**天然互文**：游戏存档的循环，在设定里是她的亲身经历。
- **她知晓五行，但不依赖五行。**
- **目标：让世界大一统，并加速这一进程。**
  - 理由：**持续的纷争只会让民生更加水深火热**。
  - 她**仍在选**：让谁成为统一的霸主？**南宋 / 金 / 蒙古 / 西夏**。
- **她要造的，是一个更大的牢笼——但这是一个"幸福的牢笼"：人们安居乐业。**
  - **她知道、也接受**：她要创造一个**不再依靠五行的世界**（大一统 + 安居乐业 = 无人再有方向 → 天下再无五行）。
  - **但这是西西弗斯式的（关键讽刺）**：**就算大一统了，也迟早会再出现觉醒者——只要有压迫、有不公、有内心的挣扎**。她的牢笼**永远修不完**。
  - **她仍在选霸主**（南宋 / 金 / 蒙古 / 西夏）——而理论上**梁峰可以成为她的第五个选项**。

- **她知道"伪神"是什么**：伪神只是概念、不是实体，思辨够强的人自会意识到；她正是这种人，**却仍选择造笼**。

> **【提议·未拍板】核心命题**：这给了故事一个真正的哲学对撞——
> **瑞杏（大一统 / 幸福 / 牢笼） vs 觉醒（自由 / 真实 / 甚至痛苦）**。
> 两者都不是纯粹的恶；梁峰站在中间。
