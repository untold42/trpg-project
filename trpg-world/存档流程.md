# 存档流程（本局结束时的记忆蒸馏）

> **誊写存档、归档、重置本局**都由系统代码完成，你（主持人）**不要写任何文件**。
> 你只做一件事：把《本局完整记录》**蒸馏进长期记忆**。

---

## 一、两个记忆库

| collection | 内容 | 规则 |
|---|---|---|
| `gm_memory`（主持人） | **客观事实**——这个世界到底发生了什么 | **只增（add）**，不改 |
| `char_memory`（角色） | **主观记忆**——某人得知 / 认为 / 打算 / 感受到什么 | **必须带 owner**（是谁的记忆） |

**关系的拆法**：客观的结盟、敌对 → `gm_memory`；A 对 B 的好恶、猜忌 → `char_memory`，owner = A。

---

## 二、蒸馏步骤

0. **先跳过所有 `【场外】` 行**：那是玩家对主持人的场外元对话（问规则、说计划、补充设定），**不是世界内发生的事**，一律不蒸馏。
1. **逐行阅读**《本局完整记录》，提炼信息。每条形如 `{time, owner?, content}`：
   - 客观事实 → `gm_memory`
   - 主观认知 / 感情 / 打算 / 情报边界 → `char_memory`，`owner` 写角色**全名**（如「上官萤」，不要写「她」）
2. **查重**：对每条待写信息，调 `DB_query_tool_in_saving`（传 collection，char 还要传 owner）拿最相似的前 4 条旧记忆——**返回里带旧记忆的 `id`**。
3. **判断 add / update**：
   - `gm_memory`：**一律 add**（客观事实不复写；后来的事实作为新条 add）。
   - `char_memory`：仅当新信息与某条旧记忆描述的是**同一个持续状态 / 认知 / 关系 / 计划**，且新信息令其**发生变化、失效或得到补充**时，才 update 那条旧记忆；否则 add。
   - **语义相似本身绝不是 update 的理由。** 两条能同时成立 → 必须 add。
4. **写入**：调 `DB_add_and_update_tool`。
   - **add**：**不用给 `id`**，系统自动编号（你给了也会被忽略）。
   - **update**：**必须给 `id`**——用第 2 步查到的那个旧记忆的 id。
   - 参数：`operation` / `collection` / `content` / `time`；char 记忆还要 `owner`；可用 `kind` 标注子类（event / fact / knowledge / relationship / feeling）。

---

## 三、信息密度

- **高密度或重要**：一句台词也可单独成条。
  例：上官萤说沧帮即日解散、原因是某某 → 一条 memory。
- **低密度**：一句话概括即可。
  例：梁峰在街上闲逛、吃了什么 → 「梁峰在扬州闲逛，吃过某某」。

---

## 四、示例

```json
{"operation": "add",    "collection": "gm_memory",   "time": "1220-01-16", "kind": "event",        "content": "沧帮与梁峰起了冲突。"}
{"operation": "add",    "collection": "char_memory", "time": "1220-01-16", "kind": "knowledge",    "owner": "上官萤", "content": "上官萤认为梁峰来意不善，打算找机会驱逐他。"}
{"operation": "update", "id": "char_3", "collection": "char_memory", "time": "1220-01-20", "kind": "relationship", "owner": "梁峰", "content": "梁峰与沧帮和好，称兄道弟。"}
```

> 注意：`add` **不带 `id`**；只有 `update` 才带 `id`（且必是查重查到的旧 id）。

---

## 五、铁律

- **只调用数据库工具**，不要输出叙事、不要写文件。
- **`【场外】` 行不蒸馏**：它是玩家对主持人的元对话，不属于世界。
- 客观进 `gm_memory`，主观进 `char_memory`，**不许混**。
- 写 `char_memory` **必须带 owner**；漏了会被系统拒绝。
- **add 不要编 id**（系统自动编号）；update 必须用旧 id。
- 拿不准是 add 还是 update 时，**选 add**（宁可多一条，不可覆盖错）。
