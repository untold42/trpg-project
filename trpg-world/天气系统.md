# 天气系统（设计文档）

> 状态（2026-09-18）：天气完全由后端代码产出，LLM 不参与。
> 本文是设计文档——不在 `主持人/`，不再全量注入。
> GM 每轮只从状态里读到当天天气（含代码算好的「影响」）。
> 代码：`trpg-server/tools/weather_system.py` + `天气数据/*.json` + `time_weather.py:update_weather`。

## 一、数据流

```
时钟日期 + 玩家经纬度
   │  weather_system.get_weather()
   ▼
按坐标定分区 → 查 天气数据/<分区>.json（每区 366 天）
   ▼
写回 游戏数据/基本信息.json 的「天气」：
   { 日期, 状况, 温度, 风力, 描述, 影响 }
```

- 触发：`engine.state_dict()` 每轮调 `ensure_today()`（惰性同步：日期变了就重查）；
  跨日时 `time_flow.pump()` 也会调。
- GM 不需要调任何工具；它从状态里读 `基本信息.天气`，按 `影响` 施加判定修正（见 `总览.md` 规则 14）。

## 二、分区：按经纬度（不再按地名）

| 分区 | 判据 | 覆盖 |
|---|---|---|
| 北部城市 | 纬度 ≥ 32.8 | 淮河以北：开封、太原、蒙古… |
| 西部城市 | 经度 < 110.5 | 四川盆地：成都、利州、峨眉… |
| 东部城市 | 经度 ≥ 118.5 且 纬度 < 33 | 江淮 + 江南沿海：扬州、临安、南京、明州、泉州、福州… |
| 南部城市 | 兜底 | 荆湖 / 江南内陆：岳阳、长沙… |

- 顺序 = 优先级，第一个命中的生效；见 `weather_system.WEATHER_ZONES`。
- 加新城市不用改任何表——坐标自动落区。
- 坐标缺失时才退回旧的地名关键词兜底（`ZONE_KEYWORDS`，仅容错）。

## 三、天气的「影响」

代码按 `状况` 查 `weather_system.EFFECTS`，写进 `基本信息.天气.影响`：

| 状况 | 影响 |
|---|---|
| 晴 / 多云 | 无 |
| 阴 | 视野略暗 |
| 风 | 轻功 +5 难度；火系效果减半 |
| 小雨 | 地面湿滑，轻功 +3 难度 |
| 雨 | 轻功 +5 难度；火系效果减半；视野受限 |
| 大雨 / 暴雨 | 轻功 +10 难度；火系无效；视野严重受限（大雨另加声音传递困难） |
| 雪 | 轻功 +5 难度；地面痕迹可见；寒冷相关判定 |
| 暴雪 / 台风 / 沙暴 | 禁止出行；强制避雨（台风另加停航） |
| 冰雹 / 雷暴 | 户外危险，尽量避雨 |
| 海雾 | 视野严重受限；停航 |
| 山雾封路 | 山路封阻 |

## 四、天气字段格式

```json
"天气": {
  "日期": "1220-01-17",
  "状况": "雪",
  "温度": "寒冷",
  "风力": "大风",
  "描述": "雪落无声",
  "影响": "轻功判定 +5 难度；地面痕迹可见；寒冷相关判定"
}
```

叙述时可在此基础上补充感官描写（云、光、水面、空气质感），不拼日期/时辰/地点。

## 五、极端天气

查表命中「极端」时，`get_weather` 内部掷 d100 定具体类型（表见 `EXTREME_TABLE`）：
北部 暴雪/沙暴/冰雹，南部 台风/暴雨/雷暴，西部 暴雨/冰雹/山雾封路，东部 台风/暴雨/海雾。

## 六、特殊改天

仅法术改天 / 极端事件等剧情需要时，GM 用 `update_weather` 工具覆盖字段。
常规天气不需要任何工具。
