# 金乌上人

- 别称：崆峒淫僧、九命豹子
- 门派：崆峒派
- 身份：崆峒派准掌派人（备位掌门），后可成为崆峒掌门
- 阵营：千灯楼走狗
- 外表：种付大叔（中年胖子形象），中之人是个瘦弱老头。外表滑稽，实则为人形肌肉壮汉
- 武力梯度：T3 · 一流上段

## 恶行录

金乌上人是全游戏最令人憎恶的角色，没有任何道德灰色地带，是纯粹的恶人：

| 恶行 | 详情 |
|------|------|
| 采阴补阳 | 擅长采阴补阳的邪功，以此提升功力 |
| 觊觎崆峒四姝 | 对梅兰竹菊（虞小梅、夏侯兰、郁竹、魏菊）皆有企图 |
| 抢亲小师妹 | 试图强娶唐默铃（唐门小师妹） |
| 暗害大师兄 | 参与暗害唐布衣（飞侠）的阴谋 |
| 窃取掌派之位 | 靠搞政治达到备位掌派人之位，非凭实力 |


## 武力评析

- 下毒+小梅联手也赢不了大师兄
- 靠政治手腕上位多于真本事
- 魏菊评其出掌「触如击弦，鸣响于脉」——攻击自带震动效果

## 在崆峒派的地位

- 准掌派人身份意味着他是崆峒派下一任掌门的第一顺位
- 与千灯楼勾结，是千灯楼安插在崆峒的重要棋子
- 若成功上位，崆峒派将落入千灯楼掌控

## 关联人物

- 虞小梅：同为千灯楼势力，但小梅的真实目标是杀死千灯楼主
- 魏菊：四姝之一，金乌觊觎的对象
- 郁竹：因体力高达60，金乌不敢碰她
- 夏侯兰：四姝之一，金乌觊觎的对象
- 唐布衣：被金乌参与暗害
- 唐默铃：被金乌抢亲
