# 日常骰子事件机制

> 玩家在城市里主动说「投骰子」才执行。时间流逝/睡觉不自动掷骰。
> 一级骰定事件类型，二级骰定烈度，混乱度把烈度往上推。
> 与旅途骰子的区别：旅途只需一次骰子（见 `旅途骰子事件.md`）。

## 流程

```
玩家说「投骰子」→ 调用 daily_event_dice 工具
  → 工具掷一级骰(d100) + 二级骰(d100) + 混乱修正
  → 主持人按返回的事件类型与档位叙述
```

## 一级骰：事件类型

```
 0-20  场景热闹 —— 码头繁忙、集市喧闹、街上有热闹。路人闲聊、商贩叫卖、小孩追跑。瓦舍勾栏、庙会香市、茶铺闲聊。
21-64  城市风味 —— 按《世界.md》里扬州的市井内容选事件：集市、瓦舍勾栏、酒楼茶坊、码头漕运、寺庙道观、节日庙会，或江湖人士出没。
65-89  有人搭话 —— NPC主动接近。打招呼、问路、搭讪、找梁峰、传话。不一定涉及现有钩子。
90-100 麻烦与危险 —— 盘查、冲突、意外、被盯上、敌对势力活跃。混乱值越高，危险越直接。
```

## 二级骰：烈度

最终烈度 = 二级骰值 + 混乱值 × 0.25

| 最终烈度 | 档位 | 含义 |
|----------|------|------|
| 0-30 | 偏顺 | 事件往有利方向发展。意外之喜、顺手之便、对方好说话 |
| 31-70 | 中性 | 按正常面貌呈现 |
| 71-99 | 带刺 | 往不利倾斜。暗藏风险、对方不友善、麻烦升级 |
| >100 | 危险 | 见血 |

## 叙述

- **偏顺**——同样的事件往轻松讲。搭话的人友善，热闹里有意外收获，麻烦刚冒头就散。
- **中性**——按原样讲。
- **带刺**——往紧张讲。来者不善，热闹藏风险，麻烦找上门。
- **危险**——见血。

## 混乱值

存于 `trpg-server/tools/游戏数据/混乱度.json`（0=太平·100=大乱，初始 0）。工具默认从该文件读取，也可显式传入。主持人可在收工时评估调整（暴露面大、卷入事件 → 上浮；静修、独处 → 不变）。
