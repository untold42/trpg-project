# 可能性骰

## 何时触发

玩家提出一件事或一次行动，其具有不确定性，则掷可能性骰。

**不需要掷的情况：**
- 文件里明确写了有/没有、能/不能
- 常识层面不可能（比如在江南找沙漠）
- 常识层面肯定有（比如扬州有茶馆）

## 机制

### 第一步：主持人 定修正值

掷骰前，主持人 根据局势给一个修正值（-50 ~ +50）：
> 「这件事对梁峰来说有多容易？」
- **+40 ~ +50**：探囊取物。T2 剑客暗杀一个街头混混——就算骰子扔出 10，加上修正值也够用了。
- **+20 ~ +35**：优势在我。用轻功尾随普通人、用内力感应铁器——这是他的长板。
- **0 ~ +15**：稍占上风。动手或说服时有一些有利条件。
- **0**：纯看运气。找东西、打听消息、偶遇——和能力无关。
- **-10 ~ -30**：逆风。用拳掌打人、在巡检眼皮底下翻墙、追一个轻功比自己好的人。
- **-40 ~ -50**：几乎白给。让梁峰绣花、写八股文、跟官府打官腔。

### 第二步：调用工具掷骰 + 修正值
```
最终值 = d100 + 修正值（范围 0~100，超出截平）
```
| 最终值 | 档位 | 含义 |
|------|------|------|
| 0-9 | 彻底失败 | 不仅没成，还惹了麻烦——被发现、被反制、消息走漏 |
| 10-29 | 失败 | 没成。但可以换个方式再试 |
| 30-59 | 有可能 | 成了但打了折扣——动静大了、花了更多钱、对方起了疑心 |
| 60-89 | 小成功 | 成了。干净利落，符合预期 |
| 90-100 | 彻底成功 | 比预期还好——附带意外收获、多听到一句话、多捡一条线索 |

## 例子

**例1：暗杀一个小人物**
- 梁峰 T1，目标街头混混 T7。主持人 定修正值 +45。
- 掷出 12。最终值 = 12 + 45 = 57 → 「有可能」
- 结果：杀了，但动静比预期大——隔壁巷子的狗叫了半条街。

**例2：找一家琴行**（纯运气·无修正值）
- 文件里扬州没提琴行。修正值 0。
- 掷出 72 → 「小成功」
- 结果：东关街尾有一家「清音斋」，卖琴也修琴。老板是个半瞎的老琴师。

**例3：翻窗进仓库**
- 轻功 55，不算长板但也不拖后腿。主持人 定修正值 +10。
- 掷出 26。最终值 = 26 + 10 = 36 → 「有可能」
- 结果：翻进去了，但跳板踩出吱呀声，灰衫人翻书的手停了一下。

**例4：混在人群里跟踪**
- 轻功尾随普通人，属长板。主持人 定修正值 +25。
- 掷出 43。最终值 = 43 + 25 = 68 → 「小成功」
- 结果：跟了一路没被发现，目标在歪脖子柳树下停了，还掏出了铜管。
