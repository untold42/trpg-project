# 五行（世界的超自然力量）

> 本文顶部「五行 / 五行神 / 江湖三层」是 GM 正典，2026-09-21 按用户口述重写。
> 本轮推翻三条旧说法：①「觉醒源于压迫」②「组织不教觉醒、只提供平台」③「神力有限、从合格者里挑」。

五行是普世的、众所周知的。江湖上少部分人拥有，分强弱。

五行的力量货真价实，而且可以很强大：无条件生火、呼风唤雨、掀起波涛汹涌——都算五行。

## 一、五行是什么：灵知

- 五行源于「灵知」：一个人对世界有独特的、脱颖而出的思考——看见了别人没看见的东西，给出了别人没给出的答案。
- 光有思考不够，还得有把这份思考变成行动的坚韧意志。
- 灵知越强，力量越强。五行是五行神对这种人持续不断、显式的奖励（不是一次性授予）。
- 行属是灵知的「颜色」（一人一种，见 §七）：行与行的分别不是元素，而是这个人给出的是哪一种答案——斩断 / 滋养 / 看透 / 烧净 / 承载。
  （五种答案的具体命题见文末【提议】，待拍板。）

### 两轴：源泉 × 技艺（关键）

| 轴 | 是什么 | 从哪来 |
|---|---|---|
| 五行（源泉） | 力量本身的强度 | 神持续奖励灵知——刷不出来、练不出来 |
| 技艺（应用） | 如何把力量用出去 | 自己练：武学 / 医术 / 兵法 / 百工…… |

- 力量 × 技艺 = 实力：有力量不会用，等于没有；技艺再高而无源泉，也只是凡人高手。
- 所以：武馆练剑、实战、拜师，涨的是「技艺」，不涨五行。
  五行是世上唯一无法靠勤奋换来的东西。

## 二、灵知无法被看见

- 没有人能看见别人的灵知：它不能被展示、不能被证明、不能被读出。
- 力量是灵知唯一的可见证据——而且只能证明「有」，不能证明「是什么」。不出手，你可以怀疑他一辈子。
- 自称无法验证：世上永远在猜「谁是觉醒者」。
- 越强越藏不住：小把戏可催动、可不催动（隐藏）；一旦呼风唤雨，满城皆知。
- 思想可以传授，灵知不能：你可以把一整套思想讲给别人听，但听懂 ≠ 它成了你的——全靠个人修为。

## 三、觉醒与熄火

- 觉醒：神性火花被点燃的那一刻，一人一生一次（五行俱全的两人除外，见 §七）。
- 熄火 ≠ 变坏：善与恶都是方向，都能点燃五行。
- 熄火 = 你的思考不再是你的。两条路：
  1. 自弃：你累了，不再想了（岁月）；
  2. 被渗透：别人替你把答案回答掉，你接受了（敌人最有效的灭火方式）。
- 庸常即是渗透：伪神没有主体，但它一直在把现成的答案送到你面前。
- ⚠️ 苦难既非必要、也非充分，且不可量化。
  有不受苦而觉醒的人，也有受尽苦难而不觉醒的人；苦难只提供问题，答案得自己给。
  明令：不得做任何「苦难 / 压迫 → 数值」的映射。

## 四、五行神（五尊）

五尊神各有性情，各自认得出合自己胃口的灵知。

| 神 | 性情 | 认得出的灵知 |
|---|---|---|
| 金·蓐收 | 肃杀凌厉 | 判断力、执行力、武功 |
| 木·句芒 | 温柔活泼 | 温柔、耐心、共情 |
| 水·玄冥 | 沉稳安静 | 冷静、沉着 |
| 火·祝融 | 威严炽烈 | 热血、豪放、武功 |
| 土·后土 | 厚重包容 | 慈爱、领导力、学识 |

- 授予只看一样：灵知——不论善恶，不论破坏还是救济。所以觉醒者里什么人都有。
- 神是流量，不是存量（2026-09-21 定）：它不是一池等着分的水，是一条一直在流的河——奖励是持续的、不设配额。
  - （【提议】河的源头是当世活着的灵知——「神源于人」的字面机制。待拍板。）
  - 有一条不变：觉醒者尽数灭亡 → 神随之消亡。
- 神不筛人（核心）：它按灵知发牌，连未来的弑神者也照样给——一旦开始按立场筛，它就变成伪神了。
  → 弑神者最锋利的刀，是神亲手递过去的；神知道，还是递了。

## 五、五行神与「伪神」（立场，无对错）

- 五行神 = 灵知（每个人自己给出的那个答案）。
- 伪神不是一个存在，而是由众人的意识与上层建筑构成的「现成答案」——人自愿走进的牢笼。
  → 一句话对照：灵知（gnosis）↔ 流俗之见（doxa）。
- 两者没有对错，只有立场：一边要世界由「意志与真实」驱动，一边要世界由「秩序与安稳」运行。
- 社会阶级越高，越接近伪神：不是权力消磨了意志，而是权力让人不必自己回答（总有人替你回答）。
- 五行神不筛人：一旦开始筛选，它就变成伪神了。

# 六、江湖三层（离灵知 / 离现成答案的远近）

| 层 | 是谁 | 觉醒者 | 它们教的是什么 |
|---|---|---|---|
| 最接近神 | 五支组织：泥教、锦香宫、白鲨帮、鬼门关、丐帮 | 大半 | 新的、尚未被承认的思想 + 技艺 |
| 江湖代表 | 六大派、唐门 | 寥寥几人 | 正统、现成的思想（背下来就行） |
| 最接近伪神 | 南宫世家、上官世家 | 无 | 答案由别人提供（礼制、利益、体面） |

- 统称「五支组织」（2026-09-21 定）：锦香宫 / 白鲨帮 / 鬼门关 / 丐帮 / 泥教。
  旧称「五平台组织」「五支同源组织」不再使用。
- 它们教思想、教技艺，但不教灵知：把人放在一套活的思想前面，能不能自己想通，全看个人修为。
- 它们对五行神也都一知半解。
- （【提议】「正统教现成答案、异端教新思想」是 2026-09-21 推导出的解释，取代旧句「离压迫越近，觉醒越多」。待拍板。）

# 七、五行俱全的两人（唯一例外）

世人一生只能觉醒一行。只有两人五行俱全，且成因不同、正好互为镜像：

| | 梁峰 | 瑞杏 |
|---|---|---|
| 五行 | 全 0（五门皆开，未成任何一人） | 全满（精通五行） |
| 成因 | 五神共选之子——五尊神把神力押在他一人身上，千年一遇 | 多周目累积（每个周目一种答案，活过五种）+ 五行是弑神的钥匙 |
| 存在型代价 | 没付过 | 付了五次 |
| 灵知 | 还没有 | 太多，多到要毁掉灵知 |

- 瑞杏即弑神者：神本身杀不了，弑神 = 杀掉 / 熄尽所有觉醒者；而杀觉醒者需要力量，力量只有被神奖励过的人才有。
  → 能弑神的人，只能是神奖励过的人。

  瑞杏（五行俱全）· 瑞笙（金行）· 万里鹏程（土行）。

# 时代背景

## 一、年代与天下格局

- 朝代：南宋宁宗年间
- 故事元年：嘉定十三年（1220年）
- 故事跨度：嘉定十三年至嘉定十七年前后（1220—1224年）
- 皇帝：宋宁宗赵扩（1194—1224年在位）
- 都城：临安府
- 天下格局：南宋、金、西夏、蒙古四方并立。南宋经济繁荣但政治积弊严重；金国国势衰落并受蒙古威胁；西夏日渐衰弱，在金蒙之间求生；蒙古迅速崛起并开始觊觎中原。

## 二、南宋

南宋定都临安，宋宁宗赵扩在位。嘉定十三年时宁宗已经暮年，朝政逐渐受到重臣和官僚集团影响。

南宋经济、商业和手工业高度发达，但政治体系积弊严重。土地兼并、财政压力、官僚腐败和军政问题长期存在。朝廷内部主战派与主和派斗争不断，主战派主张北伐收复中原，以部分武将和激进文臣为代表；主和派主张维持和议、休养生息，势力更强，其中部分官员实际上借和议维护自身利益。

边疆方面，襄阳是重要军事重镇，宋金边境冲突持续。枣阳、唐州等地经常受到金兵游骑侵扰。前线军粮和军械运输过程中存在克扣现象，而临安等繁华城市仍维持着歌舞升平的生活。

南宋社会因此呈现出明显矛盾：经济高度繁荣，但国家财政和军事体系不断恶化；士人重视文章与理学，但官僚阶层逐渐脱离民间；边军承担战争压力，朝廷却难以提供充足的资源。

## 三、金国

金国已经据有中原百余年。嘉定十三年由完颜珣在位，国势逐渐衰落。

金国南面与南宋存在军事冲突，北面则受到蒙古不断增长的军事压力。宋金边境摩擦持续，枣阳、唐州一线经常发生战事。

金国仍然拥有庞大的疆域和军力，但内部统治能力已经开始下降。蒙古的崛起进一步加速了金国的衰落。

## 四、西夏

西夏控制河西走廊，经过李安全、李遵顼等时期后国势日渐衰弱。

面对金与蒙古两大势力，西夏缺乏独立抗衡的能力，只能在两者之间周旋求生。边境局势动荡，部分边民受到战争影响而迁徙。

## 五、蒙古

铁木真统一蒙古诸部后建立强大的草原政权，并迅速向外扩张。

嘉定十三年时，蒙古正在进行西征，同时已经开始将目光投向中原。蒙古是四国中最具扩张能力的新兴势力。

其崛起将逐渐改变金、宋、西夏之间原有的政治格局，并最终成为南宋最大的北方威胁。

# 六、社会结构

## 士

南宋科举主要分解试、省试、殿试三级。解试合格者称举人，省试合格者称贡士，殿试合格者称进士。南宋没有明清那种“县试、府试、院试”的童试体系，也没有“乡试—会试—殿试”的明清式层级名称。

三年一科，每科录取进士约三四百人。理学逐渐成为正统，朱熹《四书章句集注》是重要读物。

生员可以免部分徭役、见官不跪、入府学并领取廪米；举人取得候选官资格。绝大多数读书人终生无法进入官场，落第文人常以塾师、账房、代写书信、算命测字等谋生。

## 农

土地兼并严重，富者田连阡陌，贫者无立锥之地。荆湖北路属于重要稻作区，一年一熟。

农民除承担两税正税外，还需要缴纳免役钱、折帛钱、经总制钱等杂税，并承担修河、筑城、运输军粮等徭役。

会子贬值进一步增加实际税负。大量失地农民进入城市和码头从事体力劳动。

## 工

南宋手工业高度发达，主要包括丝织、瓷器、造船、造纸、印刷和漆器等产业。

主要产地包括苏杭丝织、景德镇与龙泉瓷器、明州与泉州等地造船、建阳与临安印刷等。

各行业存在行会，行首负责协调价格、维持秩序和控制质量。城市中存在日工市场，普通劳动者可以通过搬运、修房、劈柴等工作获得日薪。

## 商

南宋商业高度发达。

长途贸易包括川盐东运、淮米西送、闽茶北上。广州、泉州、明州设市舶司管理海外贸易，进口香料、象牙、珍珠等商品，出口瓷器、丝绸等。

牙行负责撮合买卖并收取佣金，在大型商业城市和交通节点拥有较强势力。

# 七、经济与货币

会子是南宋重要纸币。开禧北伐后会子大量发行并持续贬值，嘉定年间一贯会子的实际购买力已经明显低于名义价值。

日常交易主要使用铜钱，大额交易使用白银等贵金属。

# 八、日常生活

卯时（5—7时）城门开启、早市开始；午时用午食；申时饮茶；酉时（17—19时）日间工作逐渐结束，部分地区开始夜市；戌时至亥时（19—23时）酒楼最为热闹；子时（23—1时）理论上进入宵禁。

不同城市实际执行情况不同。临安可以出现通宵活动，部分商业区域和交通节点也可能不严格执行宵禁。

普通平民通常一日两顿，常见食物包括炊饼、腌菜、面片汤和面食。茶是全民饮品，酒分官酒与私酒。

城市内部主要步行，远距离出行可以雇轿、骑驴或乘船。长江、汉水与运河构成重要水路网络，水运承担大量人员与货物运输。

# 九、法律与地方秩序

知县负责县政，知府负责府政；县级主要官员包括知县、县尉、主簿、县丞，分别处理行政、治安、文书和赋税等事务。

胥吏虽然没有正式官品，却长期掌握基层行政事务，部分职位具有家族传承性质。地方官员任期有限，而胥吏熟悉当地事务，因此基层实际权力并不完全掌握在正式官员手中。

乡村实行基层互保制度，本世界采用十户一甲、十甲一保。城市厢坊承担类似的基层管理功能。

普通百姓打官司成本较高，需要承担状纸、差役、师爷润笔等费用，因此民间纠纷经常通过族长、行首、乡绅等地方人物调停。

# 十、信仰与民俗

佛寺和道观遍布城乡。全真教在北方影响较大，正一道在南方更盛，普通百姓通常不会严格区分佛道信仰。

关羽崇拜十分普遍，江陵、荆襄等与关羽历史有关的地区尤其兴盛。城隍信仰遍及城市，土地公庙遍布乡村和街巷，妈祖信仰在东南沿海地区盛行。

主要节日包括元旦、上元、寒食、清明、端午、七夕、中元、中秋、重阳、冬至和除夕。

# 十一、男女与家庭

婚姻遵循父母之命、媒妁之言。男子通常十六七岁开始议亲，聘礼和嫁妆负担较重。

纳妾合法，妾的社会地位明显低于正妻。寡妇改嫁并非法律禁止，但社会评价较差。

女子可以参与一定程度的经济活动，例如经营茶馆、售卖小吃、从事针线和商业活动，但正常情况下不能参加科举。

## 女子科举与魏菊

南宋曾存在女子应试的先例，如林幼玉、吴志端，但女子参加科举并未形成稳定制度。

魏菊经过层层选拔考中状元，轰动天下。朝中重臣以“雌鸡司晨”等理由反对女子入仕，宁宗最终赐婚，将魏菊嫁给德宣节校尉。

德宣节校尉为从八品武官，并有虐妻致死的恶名。新婚之夜，校尉府三十余口被杀，凶手为杏花仙，魏菊因此获救。

事件之后，魏菊对朝廷彻底失望，发誓永不入朝为官。此后女子参加科举的道路被彻底封死。

# 十二、武林

江湖并不是独立于世俗社会之外的体系。门派拥有自己的传承、戒律和势力范围，但仍然需要与官府、商人、乡绅、百姓和其他社会组织发生联系。

名门大派通常保持独立，同时可能与地方官府存在往来。

# 十五、江湖与世俗

江湖与普通社会不存在绝对边界。

酒楼、茶馆既经营饮食，也是消息传播的重要场所；寺庙、集市和商业街中同时存在普通百姓与江湖人士。

江湖人同样需要吃饭、住宿、交通和交易，因此门派、商人、官府、帮派和普通百姓之间始终存在利益交换。

江湖真正特殊之处，不是它脱离了世俗，而是其中的人拥有普通社会难以接触的武学、组织关系和暴力资源。

# 十七、时代氛围

嘉定十三年的南宋处于旧秩序尚未崩溃、新秩序已经出现的阶段。

南宋依旧繁华，但政治日益腐朽；金国仍据中原，但已经走向衰败；西夏苟延残喘；蒙古则迅速崛起。

庙堂、边疆、城市、乡村与江湖共同构成这个时代。

普通百姓关心粮食和税赋，士人关心科举与仕途，商人关心货物和利润，军人关心战争与军饷，门派关心传承与势力，而隐藏于社会各处的江湖组织则有自己的利益和秘密。

表面上，天下仍然维持着原有秩序。

实际上，政治、经济、军事和江湖力量都已经开始发生变化。

嘉定十三年，是这个时代变化真正开始显现的节点。
