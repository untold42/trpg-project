# 天气系统

> 数据驱动：天气不靠主持人编，按日期 + 区域查表。

## 触发时机

**每天首次读取天气时**（起床、出门、进入新场景）调用 `get_weather` 工具：
- 工具自动读 `基本信息.json` 的 `时间.日期` + `位置.区域`
- 查 `trpg-server/tools/天气数据/{分区}.json`，把结果写回 `基本信息.json` 的 `天气` 字段

> 规则：**改日期就必须同步天气**（跨天/睡觉/跳时间后，下一次出门或叙事前查一次天气）。

## 区域划分

| 分区 | 覆盖范围 | 气候特征 |
|------|---------|---------|
| 北部城市 | 淮河以北·开封·大名·太原·蒙古 | 四季分明·冬雪·夏雷雨 |
| 南部城市 | 江南·岭南·荆湖·临安·岳阳 | 湿润·梅雨·台风·极少雪 |
| 西部城市 | 四川盆地·成都·利州 | 阴天多·雾重·秋雨连绵 |
| 东部城市 | 沿海·明州·泉州·扬州·福州 | 海风·台风·温和 |

玩家当前分区由 `基本信息.json` 的 `位置.区域` 反推（扬州=东部城市）。

## 天气类型效果

| 类型 | 效果 |
|------|------|
| 晴 | 无影响 |
| 多云 | 无影响 |
| 阴 | 视野略暗 |
| 风 | 轻功判定+5难度·火系效果减半 |
| 小雨 | 地面湿滑·轻功判定+3难度 |
| 雨 | 轻功判定+5难度·火系效果减半·视野受限 |
| 大雨 | 轻功判定+10难度·火系无效·视野严重受限·声音传递困难 |
| 雪 | 轻功判定+5难度·地面痕迹可见·寒冷相关判定 |
| 极端 | 暴雪/台风/沙暴/冰雹/暴雨/雷暴/海雾——严重时禁止出行·强制避雨·可能触发事件 |

## 天气字段格式

```json
"天气": {
  "状况": "大雨",
  "温度": "温暖",
  "风力": "强风",
  "描述": "雨幕密集"
}
```

- `状况`、`风力`、`温度`、`描述` 由 `get_weather` 工具自动写入
- 叙述时可在此基础上补充感官描写（云、光、水面、空气质感），不拼日期/时辰/地点

## 极端天气细则

`get_weather` 查表命中「极端」时，工具内部掷 d100 确定具体类型：

| 分区 | 极端类型 | 概率 |
|------|---------|------|
| 北部 | 暴雪 / 沙暴 / 冰雹 | 40% / 20% / 40% |
| 南部 | 台风 / 暴雨 / 雷暴 | 40% / 40% / 20% |
| 西部 | 暴雨 / 冰雹 / 山雾封路 | 50% / 20% / 30% |
| 东部 | 台风 / 暴雨 / 海雾 | 50% / 30% / 20% |

极端天气时，在叙述中体现对应灾害的影响（封路、避雨、停航等）。
