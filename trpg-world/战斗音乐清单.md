# 战斗音乐清单

> 格式：`- 曲名｜绑定：说明`（绑定可省略）。
> **只给战斗系统用**，叙事小模型看不到。
> **绑定**（可选）= 人物 / 地点：填了则**仅当该对象在场**才进候选（如 `温夫人`），用于 boss 专属曲。
> 只有实际存在的 `assets/音乐/*.mp3` 才进候选。
>
> **选曲依据（给模型看的）**：每条说明都标了「情绪 + 战况」。
> 判断顺序：先看**敌我强弱**（压制 / 势均力敌 / 劣势 / 绝境），再看**性质**（对决 · 追杀 · 军阵 · 决战 · 苦战）。

- 侠心凛然：**侠气凛然·正面对抗**。中等强度的常规交手——路见不平、狭路相逢；不惨烈、不绝望。**势均力敌的普通战斗默认用这首**。
- 千里不留行：**洒脱迅疾·快意恩仇**。轻快凌厉的追杀 / 突围 / 独行——十步杀一人、事了拂衣去。适合**主动进攻、速战速决、以强凌弱**。
- 历劫知侠气：**历经磨难·由苦转韧**。久战不下的鏖战——以弱抗强、咬牙死撑、屡挫屡起。适合**被压制却不退**。
- 吾往矣：**悲壮决然·虽千万人吾往矣**。赴死 / 断后 / 孤身赴险——明知不敌仍向前。适合**绝境中的抉择与牺牲**。
- 恐怖君临：**威压恐怖·强者压迫**。魔头或绝顶高手现身，杀气笼罩、敌强我弱。适合**面对压倒性强敌**时的窒息感。
- 战令堂：**军阵号令·肃杀有序**。行军 / 列阵 / 军旅对抗——旗帜、号角、成建制的厮杀。适合**官兵、军队、多人列阵**。
- 斩破昊天：**爆发绝强·高潮决战**。绝招对轰、力挽狂澜、毕其功于一役。适合**决胜时刻 / 放大招 / 拼死一搏**。
- 最崎岖的路：**艰险跋涉·苦战求生**。地形险恶、久困脱身、绝境翻山。适合**劣势中的挣扎与逃命**。
- 仙侣宫，哪吒令，龙游浅水｜温夫人：仙逸灵动而暗藏杀机；**温夫人**专属一战。
- 君所愿兮江湖行，最是轻狂不愿醒｜瑞笙：江湖少年的轻狂快意；**瑞笙**专属一战。
- 晚钟声，千灯行｜千灯楼：诡异压抑、杀机四伏；**千灯楼**相关的战斗。
- 金光裂重云，指天唤霹雳｜王二壮：**神功天威·雷法轰击**。毁天灭地的震撼——绝招、天雷、以力破法。适合**面对王二壮**或同级的雷霆绝技对决。
- 鬼门关｜赵逵：**凶险阴森·不祥杀机**。鬼气森森的绝境——追杀、私刑、九死一生。适合**面对赵逵**或阴森凶险的绝境战。
- 龙卷疯｜刘鄂：**狂乱暴走·混战危局**。狂风骤雨般的疯狂——乱战、暴走、局势失控。适合**面对刘鄂**或群魔乱斗。
