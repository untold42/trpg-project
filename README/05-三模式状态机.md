## 七、三模式状态机（探索 / 叙事 / 战斗）

```
        ┌────────────────────────────────────────────┐
        │              探索模式（地图）                │
        │  WASD 自由走 · 时钟 RUNNING · 无 LLM          │
        └───────┬──────────────────────────┬─────────┘
                │ 玩家输入（行动/说话/继续/主持人）│ 敌对
                ▼                          ▼
        ┌───────────────────┐      ┌───────────────────┐
        │   叙事模式（场景）  │      │   战斗模式         │
        │  背景图 · LLM · 钟 RUNNING（请求窗口暂停）│  回合制 · 钟 ACCRUING │
        └─────────┬─────────┘      └─────────┬─────────┘
                  │ 主持人裁定 resume_exploration │ 战斗结束
                  └──────────────┬────────────┘
                                 ▼
                            回到探索模式
```

### 核心决策

进入叙事由玩家发动；退出叙事＝玩家点「探索」按钮（确定性，不靠 GM）。
这样玩家在叙事中不能自行在地图上乱走——正是设计意图。约束靠模式本身（叙事下根本不渲染地图），
而非提示词自觉（与§5.7 信息边界同源：约束必须机械化）。

### 实现

- 前端：`GameController.gameMode: "explore" | "narrative" | "battle"`。
  - 探索 = `<GameMap zoom={18}>`（`Map.tsx` 的 `onMove` / `playerOverride` / `extraFootprints`）；
  - 叙事 = `GameScene`（探索时 `display:none` 隐藏但不卸载 → 叙事进度不归零）；
  - 战斗 = `BattleScene`。
- 切换：
  - 探索 → 叙事：`sendAction` 时带 `坐标`（光标）+ `上一坐标`；发出后 `setGameMode("narrative")`；
  - 叙事 → 探索：「探索」按钮是纯前后端逻辑——`main.py` 短路到 `engine.enter_explore()`，直接发 `ui_event("mode", mode="explore")` + 通用 BGM（不经 GM、不调大模型；`resume_exploration` 已退役）；前端 `kind:"mode"` 处理；另有 `POST /explore` 入口；
  - 战斗：`start_battle` → `kind:"battle"`。
- 坐标 → 硬事实：`main._apply_move()` 调 `update_location`（更新位置 / 足迹 / 城内城外 / 方位），并把 【移动】梁峰自「A」来到「B」，相距约 N 米。（耗时提示） 注入本轮 `pending_notes`——承总纲第 5 条。
- 协议：`ui_events.KINDS` 加 `mode`；`总览.md` 通用规则 14 说明三模式。

### WASD 连续移动

`Map.tsx` 的 `ExploreControls`：
- 命令式 Leaflet：玩家标记用原生 `L.marker`，rAF 逐帧 `setLatLng` + `map.panTo` 相机跟随—— 不触发 React 重渲染；
- 速度与时间挂钩：真实速度 = 游戏内步速 `× 时钟倍率`（时间快 N 倍，标记也快 N 倍，游戏内步速才真实）；按住 Shift ×2.6 奔跑；
- 位置真相在 `posRef`（每帧读写）；松开按键时才回调父组件（同步迷雾轨迹 / 行动坐标）；
- 输入框聚焦时不拦截 WASD（打字不移动）。

### 上一轮状态 + 当前状态（供模型自行对比）

`engine.state_stack = deque(maxlen=2)`（长度上限 2、不累积）：每轮末 `append(本轮状态)`，
下一轮把栈顶（上一轮）与现拼的「当前状态」一起发给 LLM，模型自行看出时间 / 地点 / 数值的变化，代码不算差值。
