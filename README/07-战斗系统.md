## 十、战斗系统

> 设计详见 `trpg-world/战斗系统.md`；本节记架构决策与数据链。

### 决策（v0.1 ✅）

- 战斗是独立子状态机，不复用 GM 工具循环：`/battle/*` 自成一套（HTTP），战斗推进不经 `/action`。
- 事件边界：GM 只在两处介入——①开战（工具 `start_battle` → UI 事件 `kind:"battle"`）②结束（结果 → `pending_notes` → 下一轮 GM）。战斗过程不调用大模型叙事（快）。
- 硬事实全归代码：`tools/战斗/battle.py` 负责命中 / 伤害 / HP / 内力 / buff / 移动 / 射程 / 胜负的计算，所有全局策划系数统一读取 `trpg-server/配置/战斗数值.json`；模型没有任何数字输出权。
- AI 只做两件事：①判玩家「思路」→ 只出「评价」枚举，代码查表成修正（只作用于伤害）；②阵营决策 → 只出 `{动作,目标,移动}`，代码校验降级。
- 模型可切：思路判定默认小模型、战斗界面内可切大模型；设置存 `sessions/battle_settings.json`（不进 `游戏数据/`、不进每轮状态块）。
- 模拟战斗：环境设定里直接开局，`模拟=True` 时不回写真实 `状态.json`，且结果不注入下一轮叙事。
- NPC AI 全归代码（战术层 L2 枚举+打分 + L3 `clone` 前瞻）；`TRPG_BATTLE_AI=model` 可切回小模型。
- 定位：TRPG 主干 + 战棋战斗模块；选定路线 B「深化为真战棋」（见 `TODO.md`）。

### 分层与数据链

```
前端 battle.tsx ──HTTP──► main.py /battle/* ──► battle_session（单例/生命周期/写回）
                                                      │
                                        battle_runner（阶段机 + 战局快照）
                                                      │
                                   ┌──────────────────┴──────────────────┐
                                   ▼                                     ▼
                            battle_ai（AI）                        battle（数值·纯代码）
                                   │                                     │
                            小模型 / 大模型                    读：状态/属性/基本信息/招式表/武力排名
```

### 一回合

```
begin_round（定先手 + DoT + 内力回复）
  → 先手方阶段：玩家先动（判思路）→ 该侧 NPC 一次
  → 后手方阶段：另一侧
  → end_round（buff 计时）
```

每回合 ≤ 3 次模型调用（玩家判定 1 + 友方 1 + 敌方 1；思路为空则 0 次判定调用）。

### 命中 / 伤害（实现版）

```
命中 = d100 + clamp(round((攻方兵器 − 守方轻功)/5), ±25) + 命中buff + 位置(背袭+15/夹击+8)
       <20 落空｜20–59 ×0.8｜60–89 ×1.0｜≥90 会心 ×1.5
伤害 = 威力 × 兵器/100 × 梯度系数 × 武器类型(利器1.25/钝器1.0/徒手0.9)
     × 五行克制(克1.3/被克0.8) × 位置(背袭1.3/夹击1.15)
     × (1 + 思路修正/100) × buff − 减伤
```

### 数值要点

- 网格 10×6（切比雪夫距离）；先手方→后手方阶段制；玩家 6 动作：移动 / 舞剑（普攻不耗内力）/ 防守 / 技能（五行）/ 交流（队友或对手）/ 撤退。
- 五行相克；武器类型（利器×1.25+流血 / 钝器×1.0+会心眩晕 / 徒手×0.9）。
- Buff：流血 / 中毒 / 内伤 / 破绽 / 眩晕 / 护体 / 士气 / 动摇 / 致盲 / 洞察 + 蓄力 / 穿甲。
- 地形：`Battle.terrain` + `blocked()`（房屋/墙阻挡，河可涉水）+ `reachable_cells()`；`state()["地形"]`。
- 技能 AOE：`skill_centers/skill_area/_is_aoe`，以所选格为中心、半径 N 内。技能速记：舞剑=普攻不耗内力；水天一色=自身·洞察（命中+30 / 会心线−15，2回合）；生生流转=自身·蓄力（≤3层）；胧/冰=选格 AOE。

### 数据写回

- 战斗状态只在内存（`battle_session._RUNNER`），不落盘。
- 结束 → 玩家 生命/精力/伤势 → `游戏数据/状态.json`（模拟战斗跳过）；结果摘要 → `session.pending_notes` → 下一轮注入 GM。

### 前端

`in-game/battle.tsx` + `styles/Battle.css` + `in-game/BattleBoard.tsx`（等轴测 SVG 2.5D：人物=锥+球、房/墙=长方体、河=凹陷、树）：10×6 网格 + 动作菜单 + 目标点选 + 思路输入框 + 滚动日志 + 顶部小/大模型开关 + 结算浮层；主菜单「环境设定」可开模拟战斗（`GET /battle/roster` → `POST /battle/sim`）。
