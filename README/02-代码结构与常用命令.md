## 三、代码结构与常用命令

```
trpg-project/
├─ trpg-map/      地图生成（世界生成器 + 瓦片 + 空间库 SQLite）
├─ trpg-server/   Flask 后端（GM + 工具 + 世界推演）
│   ├─ engine.py           会话 + 回合循环 + 状态现拼 + 过程日志
│   ├─ main.py             路由 + bootstrap
│   ├─ save_pipeline.py    存档收尾管线
│   ├─ llm.py              大模型客户端
│   ├─ tools/              工具与子系统（按归属分 4 个包）
│   │   ├─ 大模型/           大模型 function-calling 工具实现 + 注册表 + 战斗 + 路由
│   │   ├─ 小模型/           小模型三条管线（ui_sim / expression_sim / world_sim / world_worker）
│   │   ├─ 导演/             director（GLM）
│   │   └─ 核心/             共用地基（state_manager / game_clock / time_flow / map_query / ui_events …）
│   ├─ 游戏数据/           实时状态 JSON（含 基本信息.json / 时钟.json / 足迹.json）
│   ├─ 天气数据/           4 区 × 366 天
│   ├─ 归档存档/           逐字叙事归档
│   ├─ 时间影响.json       时间流逝数值参数（热改免重启）
│   └─ sessions/           current.jsonl / run_start_state.json / battle_settings.json / audit.log
├─ trpg-client/   React + Leaflet 前端
├─ trpg-world/    世界观正典
└─ trpg-db/       chroma 记忆库 + init_GM_DB.py
```

```bash
# 记忆库（trpg-db 下）
python init_GM_DB.py [--reset]

# 后端（trpg-server 下）
python main.py                         # Flask :5000

# 前端（trpg-client 下）
npm run dev                            # ⚠️ 开发就用这个；不要跑 npm run build（见顶部工作约定）
npx tsc -b                             # 改完 TS/TSX 只跑这个做类型检查

# ---- 地图：一键链路（trpg-map 下）----
python 生成.py --city 岳阳              # pbf → 世界 → 点击层 → 空间库 → 碰撞层 → 瓦片 → 拷前端
python 生成.py --city 扬州 --only tiles # 只跑某一步（pbf/world/clickable/db/walkable/tiles/sync）
python 生成.py --list
```

> ⚠️ 地图命令都已城市化：源 PBF、中间产物、瓦片、空间库、前端目录全部按城市分。
> 单步跑 `build_world.py` / `export_walkable.py` 等脚本时，必须带 `TRPG_CITY=<城市>`（否则默认扬州）。
> 完整数据流与目录约定见 §13.3 / §13.5。

前置：LM Studio 加载 `Qwen/Qwen3-Embedding-0.6B` + `qwen/qwen3-4b-2507`。
`TRPG_WORLD_SIM=0` 可关闭世界推演；`TRPG_CLOCK=0` 关闭连续时钟；`TRPG_FILE_TOOLS=1` 临时启用文件工具。
改后端代码必须重启；改规则 md 免重启。
