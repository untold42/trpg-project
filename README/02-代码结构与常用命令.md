## 三、代码结构与常用命令

```
trpg-project/
├─ trpg-map/      地图生成（世界生成器 + 瓦片 + 空间库 SQLite）
├─ trpg-server/   Flask 后端（GM + 工具 + 世界推演）
│   ├─ main.py             路由 + bootstrap
│   ├─ engine.py           会话 + 回合循环 + 状态现拼 + 过程日志
│   ├─ save_pipeline.py    存档收尾管线
│   ├─ llm.py              大模型客户端（配置驱动：`配置/大模型.json`，可热切 DeepSeek / gpt-6-luna 等 OpenAI 兼容端点）
│   ├─ 配置/               热改配置（facilities / 天气 / 成长 / 战斗数值 / 技能树 / 招式表 / 时间影响 / 移动 / 任务 / 小模型 / 大模型 / 画作 / 双GM .json）
│   ├─ 文档/               删档.md · 基础设施活动表.md · 设计-任务系统与保活机制.md · 设计-画作与后端推送.md · 设计-双GM拆分.md
│   ├─ 开发/               诊断/工具脚本（context_lens / director_probe / verify_expression / verify_quest / verify_relation / verify_save_affinity / verify_get_character / verify_gm_speed / verify_tool_intent / 重置演示档 / 导出策划数值表）
│   ├─ tools/              工具与子系统（按归属分 6 个包）
│   │   ├─ 大模型/           大模型 function-calling 工具实现 + 注册表 + `quest_arbiter`（旁路裁定）
│   │   ├─ 小模型/           小模型管线（ui_sim / expression_sim / quest_sim / world_sim / world_worker）+ `remote_model`（远端 OpenAI 兼容客户端，quest 判定用）
│   │   ├─ 导演/             director（GLM）
│   │   ├─ 战斗/             battle / battle_ai / battle_runner / battle_session / battle_settings / battle_tactics
│   │   ├─ 服务/             HTTP 路由支持（recap / factions / difficulty_settings / place_recall）
│   │   └─ 核心/             共用地基（state_manager / game_clock / time_flow / map_query / quest / ui_events / context_dump / **art** / **push** / **tool_gm** / **two_gm** …）
│   ├─ 游戏数据/           实时状态 JSON（含 基本信息.json / 时钟.json / 足迹.json）
│   ├─ 天气数据/           4 区 × 366 天
│   ├─ 归档存档/           逐字叙事归档
│   └─ sessions/           current.jsonl / run_start_state.json / battle_settings.json / audit.log / 工具日志.jsonl
├─ trpg-client/   React + Leaflet 前端
├─ trpg-world/    世界观正典
└─ trpg-db/       chroma 记忆库 + init_GM_DB.py
```

```bash
# 记忆库（trpg-db 下）
python init_GM_DB.py [--reset]

# 后端（trpg-server 下）
python main.py                         # Flask :5000

# 前端（trpg-client 下）
npm run dev                            # ⚠️ 开发就用这个；不要跑 npm run build（见顶部工作约定）
npx tsc -b                             # 改完 TS/TSX 只跑这个做类型检查

# ---- 地图：一键链路（trpg-map 下）----
python 生成.py --city 岳阳              # pbf → 世界 → 点击层 → 空间库 → 碰撞层 → 瓦片 → 拷前端
python 生成.py --city 扬州 --only tiles # 只跑某一步（pbf/world/clickable/db/walkable/tiles/sync）
python 生成.py --list
```

> ⚠️ 地图命令都已城市化：源 PBF、中间产物、瓦片、空间库、前端目录全部按城市分。
> 单步跑 `build_world.py` / `export_walkable.py` 等脚本时，必须带 `TRPG_CITY=<城市>`（否则默认扬州）。
> 完整数据流与目录约定见 §13.3 / §13.5。

前置：LM Studio 加载 `Qwen/Qwen3-Embedding-0.6B` + `qwen/qwen3-4b-2507`。
`TRPG_WORLD_SIM=0` 可关闭世界推演；`TRPG_CLOCK=0` 关闭连续时钟；`TRPG_FILE_TOOLS=1` 临时启用文件工具。
改后端代码必须重启；改规则 md 免重启。
