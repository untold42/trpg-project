## 八、地图为主 UI + WASD 探索

### 8.1 渲染：保留 Leaflet，加一层 Canvas

Leaflet 是地图库不是游戏渲染器。WASD + 碰撞 + 动画下它会吃力，但不推倒它
（瓦片、点击层、迷雾、`/explored` 都在上面）。方案：

```
Leaflet（瓦片底图 + 坐标系）        ← 保留
  └─ Canvas Overlay（rAF 游戏循环）  ← 角色 / NPC / 特效 / 碰撞可视化
```

### 8.2 碰撞：前端矢量判定（已实现）

WASD 自由移动必须阻止穿墙 / 穿屋 / 入河。已实现为前端矢量碰撞（地形数据由空间库导出）：

- 新增 `trpg-client/src/in-game/walkable.ts`（前端矢量判定 + 网格索引）
  与 `trpg-map/draw_tiles/export_walkable.py`（从空间库导出 `trpg-client/public/data/<map_id>/walkable.geojson`）。
- 规则：除水域 / 城墙外可走；城门 25m 为出城通道；桥 100m 可走；路 ∩ 水 默认路可走。
- `ExploreControls` 走不动时沿障碍滑动（先试 X、再试 Y）；被挡时棋子描边转灰；`?nowalk=1` 关闭碰撞。
- 城门限时：`营业时间.json` 把城门定为 `卯-申`；`export_walkable.py` 导出城门 hours，前端按当前时辰判断开闭——闭门后走不了城门（城墙依旧阻挡）；`query_place/query_nearby` 结果带 `营业时间`+`现在`。
- 地形步速倍率（新，§13.6）：同一份导出里多一个 `terrain` 层，带 `mult`。
- ⚠️ 活动范围（夹取角点）必须按地图传（`area` prop），写死某城会导致走动瞬移（§17.3 #18）。

> 现有 `map_spatial_<map_id>.db` 只有几何、未成图。后续可升级为真正的路网图（Dijkstra/A*）；
> 语义可复用战斗的 `blocked()` / `reachable_cells()`。

### 8.3 相机与控制

- 相机跟随角色，玩家图标始终居中；探索模式下禁止拖动镜头（`dragging={!lockZoom}`），玩家只能 WASD 移动。
- 相机逐帧 `_rawPanBy` 整数像素拉回正中（<1px 死区防抖），`move` 节流 —— 不每帧 `panBy`（见 §十三.4）。
- WASD 产生 `MoveVector(x,y)`。
- 走路只更新坐标 / 时钟 / 足迹，不写 `history`（否则 `current.jsonl` 被脚步刷爆）。
- 输入抽象层（键盘 / 手柄 / 语音）为后续留口。

### 8.4 Enter 进入场景（代码注入地理硬事实）

按 Enter / 点击输入时，代码先自动跑地理查询，再让 LLM 生成场景：

```
玩家输入
  → 代码：query_nearby / city_context / description / place_notes / 当前时刻 / 天气
  → 拼成「此地是什么、旁边有什么、什么时辰、天气如何」
  → 注入 prompt → LLM 生成叙事
  → 前端切到对应背景图（由坐标 / 地点类型确定，不再靠小模型猜）
```

- 这是总纲第 5 条的直接应用。背景图改为由坐标 / `ancient_kind` 确定性映射。
- 场景必须有显式出口（「离开」按钮 / 主持人裁定），不能只等 LLM 说"你可以走了"。
- 已落地形式：`main._apply_move()` 在玩家输入时注入【移动】系统提醒。

### 8.5 足迹的复用

`游戏数据/足迹.json` 现为 `{"points":[{lon,lat,地点}]}`。

| 层级 | 用途 |
|---|---|
| MVP | 迷雾揭示（已有）+ 轨迹可视化 |
| 亮点 | 足迹 = 在场追踪：WASD 走过某处，附近 NPC 自动记为「在场」→「知悉」 |

> 为什么是亮点：这顺手解决了最大技术债之一（§5.7 信息边界的"在场"标注）。机械、免费、确定性。

⚠️ 必须降采样：WASD 每秒产生几十个坐标。按网格去重（2m 格）/ 最小距离阈值（10m）/ 设上限 + 老化。

## 九、古钟 HUD

```
┌─────────────────────────┐
│   ◜ 十二时辰环 ◝         │   子丑寅卯辰巳午未申酉戌亥 环绕
│     指针平滑旋转          │
│   ☀ ────●──── ☾        │   日月弧：昼在日侧，夜到月侧
│  未时 · 二刻              │   时辰 + 刻
│  嘉定十七年 三月初五      │   日期（年号 + 月 + 日）
└─────────────────────────┘
```

元素：① 十二时辰环 + 平滑指针 ② 刻刻度（8 格） ③ 日月弧 + 昼夜配色 ④ 日期文字。
风格：楷/宋体 + 青铜或木质配色。位置/层级/尺寸均为 CSS 变量（`--clock-top` / `--clock-z` / `--clock-size` …）。
日期与年号来自后端锚点（`anchor.纪年` / `anchor.干支`），前端不再自备年号表。

> ⚠️ 教训：曾加过「漏刻水滴」装饰，但它固定在盘底 → 正好落在 午时 位置，被误读成「午时有事件」的游戏标记。环上的任何固定装饰都会对上某个时辰，故移除。

技术：SVG + CSS transform。指针角度 = `(游戏刻 / 96) × 360°`，由 CSS 变量 驱动，rAF 每帧只改一个变量。整点换时辰时加一点转场 / 音效。战斗期间显示 `战 · 第 N 回合`。

实现：`in-game/Clock.tsx` + `useGameClock.ts`（锚点 + rAF 本地插值 + 暂停/恢复 + 全局重同步）+ `styles/Clock.css`。古钟在所有模式都显示（探索模式也有）。
