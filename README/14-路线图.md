## 十九、路线图（MVP 边界 / Phase 2-3 / 验收）

### 19.1 v0.2 MVP 边界（实施状态）

```
✅ 单一标量时钟（整数游戏秒）—— tools/核心/game_clock.py
     ├─ RUNNING / PAUSED / ACCRUING（三态）
     ├─ RUNNING：探索 + 叙事（LLM 请求窗口内 PAUSED）
     ├─ PAUSED：菜单 / 历史 / 失焦
     ├─ ACCRUING：战斗（begin/end_battle 已就绪，战斗流程尚未接入）
     └─ 快照 + 存档含标量；时钟.json 不进 LLM
✅ 状态现拼：每轮注入 基本信息.时间（刻级 + 纪年/干支）
✅ 上一轮状态 + 当前状态（state_stack，长度 2）
✅ 左上角古钟（SVG + rAF 插值；探索模式也显示）
✅ 年号 / 干支（南宋全表 1127~1279，收归后端）
✅ 时间影响数值：跨时辰扣精力（夜时辰更狠）+ sleep
✅ 跨日联动：切当天天气 + 触发世界推演
✅ 三模式状态机（探索 WASD / 叙事 / 战斗）
✅ 探索坐标 → 叙事：【移动】系统提醒
✅ 窗口失焦自动暂停
✅ WASD 碰撞（水域/城墙；城门限时）
✅ 地形步速倍率（官道 1.15 … 山地 0.35；右下角徽章）
✅ 多城市（扬州 / 岳阳）：资产分目录 + 前端搜索切图 + 游戏城市由坐标推导
✅ 岳阳地图（完整洞庭湖 1078 km² + 君山岛 + 锦香宫建筑群 330 亩）
❌ 未做：战斗时间折算接入、/move 边走边同步、手柄、语音、
        NPC 地图标记、昼夜光照、在场追踪、农历/节气、转场动画、
        世界地图（跳城旅行靠叙事/渡船）
```

> 与最初计划的偏离：
> - 原计划「Enter 锁定点位 → 触发场景」改为 WASD 自由走 + 按钮输入；
> - 原计划「场景离开按钮」改为主持人裁定（`resume_exploration`）；
> - 「Enter 场景 + 地理硬事实注入」以 `_apply_move` 注入【移动】提醒的形式落地。

### 19.2 Phase 2 / 3

> ⚠️ Phase 2 是这次改革的"完成标准"，不是可选项。否则 Phase 1 只是"能走路的场景选择器"。

Phase 2（让地图活起来）
- `world_sim` 人物线程 → 地图 NPC 标记（移动 / 聚集 / 离散）
- `place_notes` / `description` → 地点气泡
- 环境事件层（替代骰子）：地点定时事件（`place_notes` / `宏观时间线`）到点触发 + NPC 在场（`world_sim`）
- 昼夜光照 + 按时辰开关的铺子 / 夜市
- 足迹 → 在场追踪（接信息边界）

Phase 3（打磨）
- 转场动画、音效、时间压力机制（可选）
- 手柄支持（Gamepad API）、语音输入（STT → `/action`）
- 农历 / 节气 / 节日 / 月相

### 19.3 验收标准

时钟
- [ ] 探索模式下站着不动，古钟持续走；打菜单 / 看历史 / 切窗口 → 停；关掉 → 续走。
- [ ] LLM 请求进行中，钟不跳（请求耗时不计入游戏时间）。
- [ ] 战斗结束，时钟一次性 += 回合数 × 每回合秒；跨时辰 / 跨日正确。
- [ ] `/action` 每轮的 prompt 里时间只到刻；UI 古钟平滑到秒。
- [ ] 存档 → 读档，时钟标量一致。

地图 / 移动
- [ ] WASD 能走，撞墙 / 撞屋 / 入河被挡；闭门后走不了城门。
- [ ] 相机跟随角色；走路不产生 `current.jsonl` 行。
- [ ] 足迹增长受降采样限制（不随步数线性爆炸）。

场景
- [ ] 输入时 prompt 含代码注入的 `query_nearby` / `city_context` 结果（非模型编造）。
- [ ] 背景图由坐标 / 地点类型确定，同一地点可复现。
- [ ] 「离开」按钮能回地图。

联动
- [ ] 时钟跨游戏日 → 天气自动切换；`world_sim` 入队。
- [ ] 叙述"过了一夜"却没调 `advance_time` / `sleep` → 下一轮出现时间提醒。
