# 删档（丢弃本档 / 开新档）

> 目标：**只清「具体游戏数据」，保留 schema / 容器**；正典与跨档内容不动。
> 2026-09-17 已手工删了「测试档」，删前完整备份见 `删档备份/2026-09-17_测试档/`（含 `MANIFEST.md` + sha256）。
> 本文是删档的**清单与思路**，供日后写成自动化脚本（TODO §十一「自动删档」）。

## 一、内容三分：什么属于「档」

| 类别 | 位置 | 删档时 | 说明 |
|---|---|---|---|
| **正典（永久）** | `trpg-world/角色静态档案/`（55 正典）、`江湖势力/`、`世界推演/`、`主持人/`、`档案模板/`、`场景*.md`、`音乐*.md` | ❌ **不动** | 世界设定与规则 |
| **跨档（按规则保留）** | chroma `gm_memory`（史书）、恒存角色的动态档案 | ⚙️ 见 §五 | 「十年一档」框架 |
| **档内（删除/重置）** | 见下表 | ✅ 清 | 本档产生的一切 |

### 档内数据：清数据、留容器

| 位置 | 清法 | 保留什么 |
|---|---|---|
| `游戏数据/世界线程.json` | 重置为 `{"模拟游标":"","人物线程":{}}` | **文件 + 字段结构** |
| `游戏数据/导演简报.json` | 重置为空内容（`{"内容":""}`） | **文件 + 字段结构** |
| `游戏数据/游戏存档.md` | 清空（可留一行标题） | 文件 |
| `游戏数据/足迹.json` | `points` 清空 | 文件 + 结构 |
| `游戏数据/时钟.json` | 重置为起始年代（重开世界时） | 文件 + 结构 |
| `游戏数据/状态.json` / `背包.json` / `金钱.json` / `混乱度.json` | 重置（重开角色时） | 文件 + 结构 |
| `sessions/run_start_state.json`、`current.jsonl` | 删 | 运行时自动重建 |
| `sessions/audit.log` | 清空 | 文件 |
| `归档存档/*.md` | 删叙事归档 | 目录 |
| 空间库 `place_notes` / `place_structures` | `DELETE FROM ...` | **表结构** |
| 非正典 `角色静态档案/*.md`、`角色动态档案/{活跃,不活跃}/*.md` | 删文件 | 目录；**正典 55 不动** |
| chroma `gm_memory` / `char_memory` | 清文档 | **两个 collection** |

### 必须保留的 schema / 容器

- 空间库的**表定义**（`place_notes` / `place_structures` 等）；
- `游戏数据/*.json` 的**文件与字段结构**（重置值，不删文件）；
- chroma 的**两个 collection**（`gm_memory` / `char_memory`）；
- `档案模板/`、55 正典档案。

## 二、标准删档步骤（本次已按此执行）

1. **备份（留证）**：把要删的完整拷到 `trpg-server/删档备份/<日期>_<档名>/`，生成 `MANIFEST.md`
   （文件清单 + 字节数 + `sha256`）、数据库行导出（`空间库_见闻与结构.txt`）、chroma 快照。
2. **清世界**：重置 `世界线程.json`、`导演简报.json`；清空 `游戏存档.md`；清 `足迹`；按需重置 `时钟`。
3. **清归档 / 日志**：`归档存档/*.md`、`sessions/run_start_state.json`、`sessions/audit.log`。
4. **清见闻**：`DELETE FROM place_notes`（**保留表**）；`place_structures` 同理按需。
5. **清记忆**：chroma 两个 collection 清文档（**保留 collection**）。
6. **清非正典档案**：删非正典的静态/动态档案，**跳过正典 55**。
7. **验证**：见 §六。

---

## 三、怎么判定「非正典 vs 正典」

- **正典** = `trpg-world/角色静态档案/` 里**初始就有**的那些（55 人）。
- **实现建议**：给正典档案 frontmatter 加 `恒存: true`（配合「十年一档」，见 `TODO.md` §十五），
  删档时**只删非 `恒存` 的**——最干净、无需维护名单。
- **过渡期**（尚未加 `恒存`）：正典清单取「上次删档时的快照」或与初始基线 diff。

## 五、与「十年一档」的关系（TODO §十五）

- 每档结束 → `delete_save()`（清档内）＋ **保留**：正典恒存人、`gm_memory`（史书）、宏观时间线（`世界推演/`）。
- `char_memory` 是否跨档，取决于「梁峰是否同一人」的拍板。
- 新档从**指定起始年代**开始：只需把 `时钟` 设到该年，宏观线会自动落在对应的十年。
